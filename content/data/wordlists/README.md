# Source wordlists and concept catalogs

This directory contains read-only inputs used to select and compare candidate learning content. These files do not represent published Sensa learning packages.

## IDS Key-2016-1310

`ids-key-2016-1310.csv` is an unchanged copy of the IDS CLDF `parameters.csv` catalog pinned to commit `3428921944d66861a89e98caf61afab706fbcb1d`. It contains the complete 1,310-concept `Key-2016-1310` list.

The adjacent `ids-key-2016-1310.metadata.json` records the source, digest, license and citation. Keep the CSV unchanged so production coverage can be compared by stable IDS ID. Sensa-specific priority, production state and package coverage belong in generated batch manifests or a future coverage index, not in the source catalog.

Source: [Intercontinental Dictionary Series](https://github.com/intercontinental-dictionary-series/ids)
