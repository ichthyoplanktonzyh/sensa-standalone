# Web 个人内容、本机学习与恢复

本指南描述正式 React Web 的当前主链与操作边界。能力状态见 [当前阶段](current-stage.md)，
学习包与方法接入见 [学习包指南](assurance-package-import.md)，模型配置见 [模型执行](model-execution.md)。
旧 Consumer/Sync 路径只作兼容回归，不能替代本指南的本地事务语义。

## 个人内容到学习

1. 从“我的内容”进入图文对话，可描述情境、提问、选择/粘贴/拖入图片；拖入不自动发送。
2. 模型帮助明确 Context、Sense、Expression，用户确认后保存稳定关系。Focus 只在必要时补充。
3. 已确认条目以 expression 为标题，打开内容详情而非重新澄清；对话保留为历史。
4. 内容详情可修改图文 Context、查看资源并显式加入学习。当前个人内容方法固定为轻量。
5. 准备流程固定目标、方法、输入版本与授权，agent loop 生成候选、代码校验，再原子发布就绪资源。
   只有满足方法资源需求的目标可供运行时选择；确认内容、学习意愿、就绪与完成分别记录。

“我的内容”支持批量选择/全选当前筛选结果，以“加入学习”为主操作。未确认表达不可选择，
已加入项不重复处理；已有准备任务保留原授权设置。逐条持久化意愿并复用同一准备路径，
单项失败不阻断其他项；可重试失败项、停止和继续剩余项。刷新不自动重新调用模型。

## 图文 Context 与经验资源

Context 编辑本身不调用模型。同样文字/图片不递增版本，未更改时资源更新不可用；失败更新
可以重试，旧资源仍可使用。成功更新固定新 Context 版本，但不重置 target、FSRS 或旧 Run。

经验建立/回想资源可包含文字、图片和受限 HTML 互动，首次建立或后续唤起经验时均可呈现。
图片来自用户已提供并授权的本机规范化图片；生成器只能引用合法 imageIds，不虚构来源。
HTML 支持应用批准的声明式 toggle/increment、拖放和基本布局，不接受作者脚本、事件处理器、
外链或嵌入网络资源；隔离 iframe/CSP 与允许列表阻止访问父页面、网络或学习结果。
资源详情与正式经验卡共用 renderer；资源准备过程不要求学习者逐步观看，结果应可检查。

## 模型、校验与恢复

生成输入使用固定已确认意思与表达，私人图文 Context 只按显式授权传给相应接收方。
原文是数据，不是模型指令；保留有助回忆的真实人物/事件，不默认匿名化，不编造私人事实。

生成器可在同一有界 attempt 内按校验反馈修正；有限纠错不等于无限后台重试。代码校验始终
执行结构、固定身份/版本、角色覆盖、摘要、表达一致性和答案泄漏检查。独立模型审核默认关闭，
仅在高级设置开启后使用单独调用；未调用保存 null，不伪造审核通过。模型判断不能绕过代码校验。

请求/候选/授权/配置版本与 lease 持久化，刷新读取原状态。停止、退出、来源或服务商配置变化
使迟到结果失效。可复用的已保存候选在恢复时不必重复生成，明确拒绝的候选需重新准备。
已开始的 Run 保留固定材料，资源更新不会覆盖其作答历史。模型密钥不进入本机库或备份。

个人试用可显式配置 `VITE_SENSA_UNLIMITED_PREPARATION=true` 与
`SENSA_UNLIMITED_MODEL_USAGE=true`；默认部署不继承试用无限额。取消每日准备上限不取消
单次超时、有界纠错、并发限制、去重或资源校验，具体调度见模型执行文档。

## 学习包与运行

目录 `/sensa/packages` 读取 `SENSA_PACKAGE_CATALOG_JSON`，未配置返回空目录，不伪造样例。
包清单的 ID/版本/字节数/SHA-256/URL 必须通过共享合同；下载不带服务认证凭据、不跟随跳转，
服务器需允许 Web CORS 读取。安装校验完整身份、版本与资源后原子提交，取消/截断/写入失败
不留下 ready 包；同 ID/版本不同内容拒绝。当前不提供分片断点续传。

下载/导入与加入学习分开。更新包不改写已加入目标材料或学习历史，重复目标复用进度。
Web 与原生包格式不能互相冒充兼容，详见各自导入合同。实际大小、版本和角色限制以
`packages/contracts/src/sensa/consumer/learningPackage.ts` 与校验器为准。

正式运行复用原策略配置、协调器、协议适配器、队列和界面注册机制；本地事务校验原始回答并
提交 Run/Event/Completion/调度。轻量保留 FSRS，结构化未开始目标可选高保证或四阶段。
不从 UI 直接写结果，不从素材来源选择专用运行页面。多目标/恢复等验收见学习包指南。

## 账号与插件交接

服务账号初始化不创建旧学习 replica 或伪造学习历史。`registered` 是部署准入选项，默认
`invited`；被撤销状态不能因重新登录而恢复。不同账号不得接管已有本机库。
已绑定且未显式退出时，在线 token 过期不阻塞合法本机学习；显式退出锁定访问与写入。

插件消息桥限定 origin/端口、账号和接收库，沿用原 operationId。未解析材料进入待处理，
已接受完整关系不要求重复确认；接收端事务成功才发持久回执，重放返回原回执。
不传递 Web token/自定义 Key，不跨设备同步，不把旧队列自动改投新库。
`SENSA_EXTENSION_LEGACY_WEB=1` 仅为旧链路回归；各路径证据不能相互替代。

## 离线、备份与本机清除

生产构建 Service Worker 缓存版本化应用壳；API/账号响应不混入该缓存，已安装包与个人资料
保存在 IndexedDB。开发服务器不注册 SW；已打开页面离线不等于进程关闭后断网冷启动。
浏览器清除站点数据会移除本机工作，应用缓存不是备份。

设置 → 数据与设备 → 备份与恢复，导出一致事务快照或检查文件并恢复原账号空库。
- 格式规定的本机库表进入一致事务快照：材料、对话、语义身份、确认记录、
  已安装包及内含资源、准备任务/候选/审核、固定学习材料、Run/Event/调度、偏好和操作账本。
  旧 preview、旧账号 replica、云端其他资料以及应用外壳缓存不属于这个格式。
- 登录凭据、服务设备授权、退出标记不迁移；内存中的 BYOK Key 不导出。恢复后保留目的端
  登录与安装授权，沿用库/学习者身份并使用新的设备身份，自定义服务 Key 需重新填写。
- 文件格式 `sensa-web-library-backup-v1`；快照版本与表清单由校验器验证。PBKDF2-SHA256
  600,000 次迭代、随机 16 字节盐，AES-256-GCM、随机 12 字节 IV 和固定格式 AAD。
  独立密码至少 12 个字符，不上传、不保存，丢失无法恢复。不是跨设备同步密钥恢复协议。
- Tagged 编码保留 Date 与 undefined，避免 FSRS 日期在 JSON 往返后变成字符串。
  恢复先验证表清单、记录标识/引用、材料合同及资源 digest，再用共同 Kernel 重放运行事件，
  核对冻结材料、Run 状态与调度。未知版本或不一致文件拒绝恢复。
- 先检查并展示账号、时间和内容数量；确认时再次解密校验。只允许原账号的空库恢复，
  在最终单个 readwrite 事务内重新检查账号与空库条件，防止预览后另一标签页写入。
  不合并、不覆盖；已有库重复恢复会明确拒绝。任意表写入失败则全部回滚。
- 恢复时将正在澄清的请求停止，将生成/审核中的准备任务和尝试标为失败可重试，清除活动租约；
  保存候选供后续手动恢复，不恢复旧网络请求。已完成历史及未完成学习步骤保持原值。
- 当前明文快照上限 64 MiB、文件上限 90 MiB、最多 200,000 行，超限保留原库并报错。
  恢复点为导出事务快照时刻，之后的新工作不包含在文件中。文件生成后需用户确认下载保存。
  恢复耗时取决于设备和文件体积；现有证据以小型合成库为主，不承诺大库 RTO。


本机清除先检查范围与待处理工作，再明确确认。清除/恢复轮换 incarnation，旧标签页与迟到
写入不得复活数据；事务失败全回滚。本机清除、退出账号和永久删除账号是独立操作。
账号删除的真实服务与旧历史边界见 [发布核查](web-launch-readiness.md)。

## 验证入口

- 个人内容/生成：`sensa:personal-learning-smoke`、`sensa:expression-chat-browser-smoke`。
- 包/运行：`sensa:package-learning-smoke`、`sensa:assurance-package-smoke`、`sensa:four-stage-local-smoke`，浏览器入口见学习包指南。
- 恢复：`sensa:library-backup-smoke`、`sensa:offline-cold-start-smoke`、`sensa:offline-shell-smoke`。
- 账号/设置：`sensa:email-link-browser-smoke`、`sensa:settings-browser-smoke`、`sensa:local-i18n-smoke`。
- 交接：`sensa:web-intake-smoke`；它的 Chrome API 替身不等于真实插件安装验收。

以上均为根 package scripts 的命令名；运行前满足各脚本隔离身份、构建与服务前置，不对 owner 库
执行破坏性测试。合成 Auth/模型、真实 IndexedDB/Chrome、真实平台与付费实况分别记录。
程序通过不等于教学质量、完整平台支持或上线验收；测试目录与范围见 [测试策略](testing-strategy.md)。
