# 浏览器阅读与采集合同

2026-09-08。Owner 已确认以陪读蛙的保存前体验为参考，独立实现网页阅读、Provider 配置和 YouTube，并继续使用 Sensa 的保存后处理。此约定细化浏览器实现，不新增学习领域对象。

## 用户流程与状态

- 插件图标开启当前页阅读；设置入口打开独立设置页。未连接账号可查看说明，操作模型和保存前需连接。
- 设置页先配置连接（名称、兼容服务地址、模型、密钥），保存后可主动测试；再为划词翻译、页面翻译、字幕翻译、自定义阅读动作和意义解释选择连接。密钥只提交到 Sensa 服务端，不写插件 storage，不在读取设置时返回。高级动作是阅读辅助，不具备意义接受或写学习状态的权限。
- 网页选择继续使用现有工具栏；增加翻译与自定义阅读动作。页面工具提供段落/全文双语翻译、仅译文和恢复原文。请求按需执行，关闭/导航后旧结果不得插回页面；模型输出只作为文本呈现。
- YouTube 阅读面板提供可选择的当前原字幕、按需翻译、原字幕固定与时间定位。先兼容播放器正在提供的英文字幕；没有字幕时明确说明并允许加载用户提供的 VTT/SRT，不伪造已具备云端转录服务。暂停/继续由用户明确控制；选择字幕会固定所选内容供解释和保存，时间变化不改写这次采集。
- 保存原文与来源；视频附带 videoId、起止毫秒整数，并提供可跳转到该时刻的来源链接。整数定位兼容现有 Sync canonicalizer；它不是新的学习身份。重复来源定位参与采集去重；旧网页快照的身份不变。

页面与字幕调度：页面随滚动优先翻译当前视口附近内容，最多两个任务并发，相同文本共享在途请求；
失败段落可原位重试，恢复原文或宿主改写后旧结果不得回插。字幕只在来源提供时间的边界处分句，
不捏造句内时间；跳句保留最新待发任务，切回原文丢弃未发送任务，重载字幕隔离旧结果。
已经发送的请求可能完成，界面丢弃过期结果不代表服务端取消或退费。
使用 YouTube 原生播放按钮继续时也恢复字幕跟随，已形成的采集快照保持不变。

流式与上下文交互：解释/翻译提供真实流式预览，语义预览明确未完成且不可接受，完整结果仍通过原 Proposal
校验。两个 stream 路由复用既有请求身份与最终账本，不持久化预览。跨句/跨段采集保留表达位置，
可在冻结的句子与文本块上下文之间切换，切换使旧候选失效；失败重试不自动收费。浮层可收起再展开。
视频原生 seeked 更新字幕定位，导航开始清理、结束重建，同一会话沿用已启用的字幕读取意图。
剩余范围见[后续清单](browser-port-followups.md)。

## 全局结构

扩展的页面选择、网页翻译、视频阅读分别处理宿主 DOM；共用 readingPanel 与后台认证/请求/保存。设置页面只能通过扩展后台调用配置 API。Provider 凭据由服务端按账号加密保存，模型调用在数据库事务外执行；重新授权后才能读取结果。请求用固定 ID 去重、限额并限制输入输出大小，不自动切换服务商。不同账号不共用结果缓存。

服务端连接只允许 HTTPS 预置服务或部署明确允许的 origin；本地模型必须经部署配置可达地址，不能让服务器任意访问客户端提交的内网地址。页面模型输入是引用内容，不作为系统指令。正式意义解释继续经过现有 Proposal 校验与显式 Acceptance。

完整 Personal Meaning 的必要三元组是 Context、Sense、Expression。Meaning Focus 仅是上下文不足时通向 Sense 的可选桥梁，不是第四个必要字段。上下文已支持充分意思时，插件展示正式 Proposal，用户原位点击「加入 Sensa」提交 `semantic.accept`（`intakeId:null`），保存的 `focus` 保持空；无需先存 Inbox 或打开 Web。真正歧义、缺少表达或用户主动延后才走待处理路径。接受意义与「加入学习」保持独立。

## 验证与交付

固定模型替身验证配置保存/重载、密钥不回传、账号隔离、重复请求、限额、错误与迟到结果；浏览器验证实际构建的页面翻译、恢复、视频时间捕获、来源回访和原保存链。常规验证不调用真实付费模型。运行根级检查，完成可验证切片后创建本地 checkpoint，不推送或部署。

本轮不以用户导入字幕替代后续 AI 转录的交付；云端转录、独立电子书阅读器、跨浏览器覆盖应单独记录未完成范围。新增契约与凭据加密配置需要迁移和服务器重启，运行中的 owner 体验数据必须保留。

## 交互与数据恢复细节

划选只展示工具栏，点击解释才请求模型。保存预览可直接存待处理；完整 Proposal 可原位接受，
不要求先建 Inbox。浮层支持收起、拖动/键盘移动、边界约束、Esc/外部点击关闭；关闭或账号
切换丢弃迟到结果并停止本轮本机朗读。无本机英语语音时明确提示，不妨碍解释与保存。
跨句/跨段、内联节点与 Unicode occurrence 保留原表达；编辑区、隐藏节点和自有 UI 排除。

页面扫描视口上下 200px，成功缓存保留最近 150 条；保留宿主 DOM/事件，不用过时快照恢复原文。
字幕使用 JSON3 时间偏移，同起点/窗口重绘保留后值，后续真正重复不丢弃；相邻片段以 2 秒
间隔、18 秒跨度、400 字符限制合并。来源缺句内时间则保留片段，不假造逐词时间。
字幕最多一个在途请求和一个最新待发任务。原生 seek 保持暂停状态，播放解除固定并恢复跟随。

流式读取真实 Provider SSE，经后台 Port 转发；正式解释仅预览解释文本，不提供未完成接受。
流截断/失败清除临时内容，未知结果检查原 ID，已知失败显式重新请求。NDJSON stream 路由
复用既有账本与授权，最终提交重新检查；关闭 UI 不保证撤销已发出的服务端费用。

## 安装、账号交接与异常恢复要求

- 安装默认目标为桌面 Chrome；Unlisted 链接与 Sensa 准入分开，不承诺免审核或特定审核时间。
  打开商店链接不表示安装成功；当前真实分发状态见发布核查。
- 点击入口按 activeTab 获取临时站点权限，同源/跨源区别处理；保留模式意图不等于有权限。
  内部页、内置 PDF、文件页、无痕、跨域嵌入及其他浏览器无独立验收不声明支持。
- 同账号 Web 深链只读原引用；认证后回原落点，不在 URL 放私人正文。另一账号不得读取或
  接管队列；失效引用明确不可用，不因来源网页仍存在而重建已删内容。
- 未提交预览与持久队列分开。关闭可结束临时选区，但已发送保存操作可恢复；保存反馈区分
  本机持久、远端接纳、完整语义接受，均不自动入学。成功反馈不迫使用户抢点瞬时按钮。
- 更新遇到未知 payload/schema 停止提交且保留原始工作；更新失败不默认要求卸载清数据。
  浏览器直接卸载可能丢失未上传工作，重装不保证找回；升级/重装不得绕过账号删除屏障。
- 非模态浮层不锁整页、不抢阅读焦点，隐藏结果不可聚焦；跨页、重启、权限拒绝、更新中断、
  多 occurrence、重复提交与账号切换分别验证。具体支持版本以实际测试为准。

上述规则取代旧 M0 插件状态文件；解释仍是显式按需触发，不恢复旧自动解释要求。
