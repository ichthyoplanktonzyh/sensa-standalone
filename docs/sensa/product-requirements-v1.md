# Sensa Web 产品说明

本文定义当前生产 Web 的用户体验。领域术语与不变量由[领域文档索引](README.md)裁决，工程实现与发布方式见[工程说明](engineering.md)。

## 产品范围

当前产品由以下可共同交付的部分组成：

- React Web 应用；
- 同账号的浏览器阅读与采集扩展；
- 支撑账号、内容、学习、模型执行和同步的在线 API；
- 浏览器本机学习库与普通账号云同步。

原生客户端不在当前工作范围内。

## Web 体验约束

- 用户看到的是“内容、意思、学习、复习、练习和账号”等产品语言，不直接暴露内部领域术语。
- 页面只呈现真实数据和真实状态。内容未准备、保存失败、同步失败或服务不可用时，不显示可继续的假成功状态。
- 本机保存与云端同步是两个结果。本机事务成功后即可继续使用；同步状态单独显示并允许重试。
- 已开始的学习固定目标、方法、路线和历史。个人材料发布新版时，尚未操作的当前步骤与后续步骤可以采用同一目标、课程成员关系和语言方向下的最新版；已经发生的操作继续固定其当时材料，普通设置修改不能重写既有学习事实。
- 当前学习步骤只负责呈现和收集输入，不直接生成学习 Evidence、Completion 或调度结果。
- 活跃学习期间减少全局导航干扰；离开、中断和恢复必须保留明确语义。

## 信息架构

```text
Web
├── 首页：开始或继续学习、到期复习
├── 我的语义世界：个人意义、收件箱、来源、详情与加入学习
├── 我的学习：目标、准备状态、学习记录与学习偏好
├── 自由练习：与正式学习证据隔离的听说读写活动
└── 账号与设置：登录、同步、本机数据、服务和外观设置

浏览器扩展
└── 网页或字幕中的选区 → 解释/确认或保存待处理 → Web 内容与学习
```

首页是默认落点。主要行动是开始或继续当前可学习内容；到期复习是独立入口。没有可学习内容时，页面应引导用户从现有内容或个人表达开始，而不是展示不可用的学习按钮。

## 核心旅程

### 登录与启动

新设备通过邮箱账号进入产品并建立本机库。登录成功后立即显示应用外壳；已有本机资料立即可用，
完整云端恢复在后台进行。新设备在恢复完成前不能把尚未到达的资料显示成确定的零；恢复进度和
失败只在账号与设置的数据区域呈现，并提供重试入口。

### 语言设置与当前路线

用户在“账号与设置 → 我的语言”维护一条或多条学习路线。每条路线只表达“我正以哪种支持语言学习哪种目标语言”，并拥有自己的每日新内容数量；它不声明用户的母语、会哪些语言或熟练度。界面语言是独立设置，切换界面语言不得改变学习路线、内容语言或学习进度。

Web 与浏览器扩展分别保存各自当前使用的路线。Web 中切换路线会改变后续加入学习、包选择和首页学习队列；扩展中切换路线会改变后续网页解释、翻译、写作和采集。两边读取同一组路线，但一边的临时选择不应抢走另一边正在使用的路线。

暂停或归档路线后，它不再出现在新的操作入口中；已有学习记录和已经开始的会话仍保留原路线事实。修改路线的支持语言也只影响之后创建的内容与会话，不能重写已经生成的材料或历史。

### 外观与官方皮肤

用户在“账号与设置 → 外观”从 Sensa 策展并随当前产品版本交付的 Skin catalog 中选择完整皮肤。
每套 Sensa Skin 可以形成明显不同但内部一致的页面空间布局、responsive presentation、颜色、字体、
形状、层级、图标、插画、组件视觉配方以及受约束的密度、装饰与动效。Skin 可以把同一组页面区域
呈现为单栏、分栏、sidebar 或 dock，但所有 Skin 仍使用同一信息架构、route identity、必须存在的页面
能力、业务流程、真实数据、操作语义、逻辑阅读/焦点顺序和无障碍行为。产品不提供任意第三方 Skin
代码的运行时安装；外部创作只有经过 Sensa 的设计、代码审查与产品发布治理后，才会成为可选择的
Sensa Skin。

Skin、`light | dark | system` color mode 与文字大小等阅读偏好是相互独立的本机外观选择。切换 Skin
立即作用于当前界面，并保留其他外观选择、route、导航位置、未提交输入、焦点意图和进行中的学习/
练习状态；它不能改变
材料披露、评价、Evidence、完成、调度、保存或同步结果。系统级无障碍设置优先，颜色不能成为成功、
失败、选中或可操作状态的唯一信号。所选 Skin 在当前版本不可用时，界面回退到完整可用的默认 Skin，
不得因此修改或丢失用户数据；已随应用交付的 Skin 在离线启动时仍然可用。

### 个人内容

“我的语义世界”提供 Sensa 自身的对话入口。用户可以像进入普通对话一样直接发送文字或图片；移动端
图片选择允许从图库添加或拍照。用户也可以保留原有“记录场景”方式，先把文字、图片和熟悉表达存成
草稿，再继续澄清。当前澄清入口只支持文字与图片，不承诺音频、视频或语音输入。

空白进入、记录场景后继续，以及从收件箱打开不完整 Intake，都进入同一个澄清工作区。后两者预先携带
已有材料、来源和候选事实，而不是启动另一种流程或复制一份无来源草稿。澄清由同一个有界教师 loop
完成：模型在每个用户回合先作为语言老师理解并自然回应，同时在该回合的最终输出中判断 Context、Sense
和 Expression 是否清楚。这个判断与候选是模型最终输出的隐藏结构，不是工具调用；产品不要求用户点击
额外的“整理”或切换到抽取模式。界面只呈现对话、已经稳定的候选和必要的真实工具状态，不展示模型
隐藏推理。

所有回合遵守同一种对话协议，没有“首轮模式”和“后续抽取模式”。模型能直接回答时使用自身语言能力，
不得为了填满工作台而检索或生成候选；只有三项都清楚时才同时给出完整候选。唯一的澄清工具是按需读取
用户本机已有语义，用于判断复用关系，而不是代替自然回答或模型本身的语言判断。
确认后的 Context 只描述用户材料所支持的现实情境，不包含“怎么说”“英语叫什么”等元语言请求，也不把
澄清对话拼接成场景正文；原始材料和对话作为来源与构造记录单独保留。

用户经过澄清后明确接受 Context–Expression–Sense 关系。
缺 Context、Expression、Sense 或接受事实的内容保留在收件箱，不冒充已经确认的 Personal Meaning。
调用方已经给出 Context 时，接收端不再判断它“够不够好”，也不因当前学习路线不包含该语言
而拒绝采集。

Sensa Web 内的模型和工具只能提出或修订候选。即使候选已经完整，仍必须由用户在独立的确认动作中接受后，
应用的本机 authority 才能写入 Personal Meaning；Web 澄清 Agent 无权自动保存、自动加入学习或制造学习结果。

已确认内容在“我的语义世界”中以确认后的 Expression 作为主标题；点击后进入表达详情，而不是重新进入
澄清 Agent。详情可以查看来源、Sense、Context、图片、笔记和学习资源，并可修订 Context；修订创建新版本，
不覆盖原始接受事实。修改内容与“加入学习”是不同操作；接受一个意义不会自动创建学习进度。用户从
“我的语义世界”点击“加入学习”时，系统把当时 Web 的当前路线固定到这次课程成员关系中；之后切换路线
不会把它悄悄搬到另一条路线。

用户也可以在已连接的 Agent 对话里完成澄清和整理，并说“把这几个表达存到我的语义世界”。外部 Agent
不复用或遥控 Sensa Web 的澄清界面；它在自己的会话中形成 Context、定位后的 Expression 与已解析 Sense，
再通过同一 Intake 边界提交。Agent 的当前会话已经得到用户明确保存请求时，连接调用本身构成 one-shot
delegated acceptance，Sensa 不再要求用户对同一条内容二次确认。三项事实完整时走快轨，确有缺失时进收件箱。

用户在“账号与设置 → Agent 连接”选择 Codex、Cursor、Claude Desktop、Windsurf 或 CLI，并创建
约十分钟有效、只能消费一次的安装码。复制的安装命令不含长期凭据；安装器直接向 API 兑换后，把凭据写入
本机私有配置并登记 MCP adapter。Codex 同时安装 managed Skill；其他 MCP 客户端可通过同一 MCP prompt/
tool 说明获得 Context–Expression–Sense 格式、来源与回执语义。Skill/prompt 类似领域命令说明，不是用来替
Sensa 检查事实是否完整的运行时验证器。

浏览器扩展不参与 Agent 连接、鉴权或交付。设置页显示连接的有效/过期/撤销状态、到期时间、最近使用时间、
近期生命周期审计，并提供原子更新、撤销和本机卸载命令。更新安装只有在新安装码成功兑换后才撤销旧连接；
每个连接默认每小时最多提交 120 个新的 operation，完全相同的幂等重试不重复计数。页面不展示内部 library id。

Agent 先获得“已排队”回执，这只代表 Sensa 云端已经持久接收。用户的 Web 在登录且
联网时取回队列，本机库实际提交后才变成“已存入”，并带回“已进语义世界”或“已进收件箱”。
断网、Web 未打开或本机确认丢失时保留同一 operation 幂等重试，不把“已排队”说成“已存入”。

### 加入学习与资源准备

用户明确选择内容加入学习。系统固定学习目标、当前路线和可用方法，再准备、校验并冻结所需资源。资源失败或不完整时保留可恢复状态，不创建可开始的假目标。

从内容包加入学习时，包的目标语言和支持语言必须与当前路线精确匹配；不匹配时说明原因并要求用户切换路线，而不是把内容标成另一种语言或隐式回退。同一个稳定学习目标可以出现在多条路线中并共享记忆进度，但每条路线保留自己的来源、支持语言、材料和每日计划。

“学习包”页面按稳定 Book 展示当前路线可用内容，不把每个版本显示成另一份书。页面先展示本机缓存，
登录和打开页面不等待目录网络请求；目录在距上次检查超过约六小时后低频后台刷新，用户也可以手动
刷新。发现新版只显示真实更新状态与作者提供的变更摘要，不弹全局提示，也不自动下载或改变学习计划。

下载只把经过大小、摘要、合同和语言方向校验的不可变 Book Version 保存到本机。首次加入与新版
“应用更新”都需要用户明确操作；下载完成不等于已加入或已更新。应用新版后，新增条目进入未来学习，
删除条目退出未来计划；身份未变的目标保留原进度与复习状态。已开始的会话继续固定旧版材料与来源，
旧版及历史不被删除；Sense 或表达 Binding 身份变化时按新目标处理。

学习 Package target 的首次经验步骤允许用户添加或编辑“我的场景”（文字与图片）。场景按当前
Learning Target + Route 保存，下一次打开立即显示；学习包提供的必需经验资源仍保留为发布内容，
个人场景以清楚标识的私有 scaffold 呈现。编辑只生成新 revision，不改写已经操作的 Step，也不产生
Evidence、完成状态或调度变化。

表达揭示后，已有个人场景时显示“存入我的语义世界”。该按钮是一次明确的 direct Semantic
Acceptance：使用 Package 已固定的 Sense Version、target Binding 与当前 scene revision 直接创建完整
Personal Meaning，不进入澄清流程，也不创建第二个 Learning Target。场景后续有修改时显示可再次更新，
未修改时只显示真实的已存入状态。学习来源和 Personal Meaning 的删除、更新与进度互不级联。

未开始且支持多种方法的目标可以选择学习方法；已经开始的目标继续原方法和历史，不做静默迁移。不同方法可以有不同步骤，但共享相同的目标、事实和调度边界。

### 学习与复习

学习界面复用正式运行时、卡片、工具栏、笔记、场景、词典、例句、音频和偏好能力。开始一次会话时，系统固定目标、方法、路线、支持语言、课程来源和计划所用的材料基线；用户随后切换当前路线时，正在进行的会话仍按原上下文继续。个人材料在会话中发布兼容新版（例如补充自己的图片）时，尚未操作的当前步骤立即刷新，后续步骤也使用最新版；已经提交操作的步骤仍按当时材料重放。每一步保存成功后才能前进，刷新、暂停和重新打开应恢复同一运行及其逐步材料事实，而不是重新生成内容。

到期复习只处理已经进入 retention 的目标，不引入新内容。一次复习最多产生一次有效结果和一次调度更新；失败后的修复或重学不能重复结算原复习。

### 自由练习

自由练习可以提供听、说、读、写活动及即时反馈，但它不写入正式学习 Evidence、Completion 或 FSRS 调度。练习中发现的内容只有经过用户明确保存，才进入个人内容流程。

### 账号与数据

账号页区分：登录会话、本机保存、云同步、数据导出、清除本机数据和删除账号。退出登录不等于删除内容；清除本机数据不等于删除云端副本；删除账号需要在线重新确认。

同步冲突、未同步修改和删除中的状态必须可见。用户数据不能因为重新登录、刷新、重复请求或另一设备恢复而被静默覆盖。

普通操作只在本机即时保存，并标记新的本机内容版本；不逐操作上传。存在待同步版本时，应用在停止
操作约两分钟、连续使用约五分钟、完成一次学习会话、页面进入后台或重新联网时形成一次批量
Checkpoint；回到前台只在上次云端检查已超过约五分钟时拉取。用户可以在本页“立即同步”。没有
待同步版本且云端检查未过期时不发起整库请求。

正常同步不显示全局横幅或顶部浮层。全局提醒只用于长时间无法形成 Checkpoint、退出或清除本机资料
会丢失待同步版本，以及新设备恢复明确失败等需要用户决策的情况。Remote Intake 是独立投递邮箱，
空邮箱或一次网络失败不能被描述成“已有内容仍在队列”。

账号辅助恢复的云端备份是已确认的后续能力，但当前版本不提供备份开关、历史恢复点或恢复流程。
现有账号同步只能按同步状态展示，不能命名为“已备份”。未来只有完整上传并校验通过的不可变
恢复点才能显示备份成功；首发恢复方式是账号辅助，零知识备份可在未来作为另一模式增加。

## 浏览器扩展

扩展只在用户开启阅读模式或主动操作时读取当前页面。它可以从普通网页和可用字幕中取得选区、上下文和来源，提供解释、原位确认或保存待处理。

用户在插件中点击“登录 Sensa”已经表达了连接当前 Web 账号的意图。若同一浏览器已有有效的 Sensa
Web 会话，授权必须自动完成并返回插件，不再要求重复登录或再次确认连接；只有 Web 会话不存在时才
进入登录，登录成功后继续同一笔短时授权。授权不得把账号令牌放进页面 URL，也不得转移另一账号或
另一资料库尚未送达的材料。

扩展保存后必须区分“仍在插件队列”和“Web 已持久化”。网络中断、Web 未打开或回执未知时保留原操作并可幂等重试。扩展不后台扫描浏览历史，也不把自身队列描述为云端备份。

阅读、解释和写作使用扩展当前路线。普通阅读把页面中识别出的原文语言作为本次输入、把路线的支持语言作为输出；如果页面偶尔出现第三种语言，只改变这些片段的输入语言，不修改当前路线，也不把第三种语言记成用户会的语言。写作则从路线的支持语言生成目标语言表达。

术语表按精确的“原文语言 → 译文语言”方向保存；反向使用必须有另一条记录，不能自动把条目倒过来。术语表属于学习者的本机库，在“账号与设置 → 我的语言”旁边维护：学习者在 Web 端写一次，阅读面按发布后的副本使用，扩展不提供第二份可编辑的副本。术语表只影响用词，不改变意思，也不承诺模型每次都照做；产品界面不得把它描述成定义、学习进度或已保存的翻译。

阅读模式里可以整页朗读：按文档顺序逐块朗读，每块用它自己的语言（按块判断，一页可以引用第二门语言），正在朗读的块高亮并滚动到视野内，停止即清除。容器与可编辑区域不朗读；没有可朗读文字、语言无法确定、设备没有对应声音三种情况必须分别给出原因。朗读只用设备本机语音，不产生网络请求；学习者可以在设置页从本机音色中指定一个，指定音色只在其能发音的语言下生效。
学习者也可以在网页的输入框里写自己的语言，用同一个快捷键（`Alt + T`）得到目标语言的表达。这是唯一反向的请求（其余功能都是把读到的内容变成熟悉语言），只有学习者真的会写句子的输入框会被读取：密码框与不可编辑的框永不读取；译文先显示、由学习者决定是否替换输入框内容，未替换前原输入保持不变。该请求与阅读共用同一份账号额度。
学习者可以对某个站点说“不在这里”。这条规则在页面上和插件弹窗里都能写，范围为当前站点（不是当前标签页），页面内写入后立刻停止该页阅读；规则生效期间该站点不再被自动注入、工具栏按钮不再开启阅读，解除入口必须在插件弹窗里可见。

语音、参考、翻译或渲染能力必须按精确语言标签解析。产品只允许三种真实结果：精确支持、明确展示的兼容变体回退、不可用；不得为了让按钮看似可用而静默改用英语或把内容重标为另一种语言。

## 状态、错误与可访问性

- 加载使用稳定骨架，避免页面结构跳动。
- 正常同步不占据全局界面；空闲页面不周期性请求整库数据。
- 媒体不可用时保留文本路径并解释原因。
- 破坏性操作使用明确、不同的确认文案。
- 桌面和窄屏均保持主要旅程可操作；主要动作支持键盘和可访问名称。
- 颜色不是表达成功、失败或选中状态的唯一方式；遵守 reduced-motion 偏好。

具体 DTO、数据库表、错误码、预算数值和 Provider 配置属于工程实现，不在本文冻结。
