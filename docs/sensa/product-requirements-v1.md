# Sensa Web 产品说明

本文定义当前生产 Web 的用户体验。领域术语与不变量由[领域文档索引](README.md)裁决，工程实现与发布方式见[工程说明](engineering.md)。

## 产品范围

当前产品由以下可共同交付的部分组成：

- React Web 应用；
- 同账号的浏览器阅读与采集扩展；
- 支撑账号、内容、学习、模型执行和同步的在线 API；
- 浏览器本机学习库与普通账号云同步。

原生客户端和 `apps/web-next` 不在当前工作范围内。`apps/web-next` 的页面、fixture 和旅程不能作为生产需求来源。

## Web 体验约束

- 用户看到的是“内容、意思、学习、复习、练习和账号”等产品语言，不直接暴露内部领域术语。
- 页面只呈现真实数据和真实状态。内容未准备、保存失败、同步失败或服务不可用时，不显示可继续的假成功状态。
- 本机保存与云端同步是两个结果。本机事务成功后即可继续使用；同步状态单独显示并允许重试。
- 已开始的学习固定目标、方法、材料和历史。普通设置修改不能重写既有学习事实。
- 当前学习步骤只负责呈现和收集输入，不直接生成学习 Evidence、Completion 或调度结果。
- 活跃学习期间减少全局导航干扰；离开、中断和恢复必须保留明确语义。

## 信息架构

```text
Web
├── 首页：开始或继续学习、到期复习、同步提示
├── 我的内容：个人意义、收件箱、来源、详情与加入学习
├── 我的学习：目标、准备状态、学习记录与学习偏好
├── 自由练习：与正式学习证据隔离的听说读写活动
└── 账号与设置：登录、同步、本机数据、服务和外观设置

浏览器扩展
└── 网页或字幕中的选区 → 解释/确认或保存待处理 → Web 内容与学习
```

首页是默认落点。主要行动是开始或继续当前可学习内容；到期复习是独立入口。没有可学习内容时，页面应引导用户从现有内容或个人表达开始，而不是展示不可用的学习按钮。

## 核心旅程

### 登录与启动

新设备通过邮箱账号进入产品并建立本机库。完成初始化后，应用外壳和本机资料不应因为云同步缓慢而不可用。恢复在后台进行，界面显示非阻塞进度；失败时显示错误和重试入口。

### 个人内容

用户可以从文本或图像建立草稿，补充上下文，经过澄清后明确接受 Context–Expression–Sense 关系。信息不足的内容保留在收件箱，不冒充已经确认的 Personal Meaning。

已确认内容可以查看来源、表达、上下文、图片、笔记和学习资源。修改内容与“加入学习”是不同操作；接受一个意义不会自动创建学习进度。

### 加入学习与资源准备

用户明确选择内容加入学习。系统固定学习目标和可用方法，再准备、校验并冻结所需资源。资源失败或不完整时保留可恢复状态，不创建可开始的假目标。

未开始且支持多种方法的目标可以选择学习方法；已经开始的目标继续原方法和历史，不做静默迁移。不同方法可以有不同步骤，但共享相同的目标、事实和调度边界。

### 学习与复习

学习界面复用正式运行时、卡片、工具栏、笔记、场景、词典、例句、音频和偏好能力。每一步按照固定材料呈现，保存成功后才能前进。刷新、暂停和重新打开应恢复同一运行，而不是重新生成内容。

到期复习只处理已经进入 retention 的目标，不引入新内容。一次复习最多产生一次有效结果和一次调度更新；失败后的修复或重学不能重复结算原复习。

### 自由练习

自由练习可以提供听、说、读、写活动及即时反馈，但它不写入正式学习 Evidence、Completion 或 FSRS 调度。练习中发现的内容只有经过用户明确保存，才进入个人内容流程。

### 账号与数据

账号页区分：登录会话、本机保存、云同步、数据导出、清除本机数据和删除账号。退出登录不等于删除内容；清除本机数据不等于删除云端副本；删除账号需要在线重新确认。

同步冲突、未同步修改和删除中的状态必须可见。用户数据不能因为重新登录、刷新、重复请求或另一设备恢复而被静默覆盖。

## 浏览器扩展

扩展只在用户开启阅读模式或主动操作时读取当前页面。它可以从普通网页和可用字幕中取得选区、上下文和来源，提供解释、原位确认或保存待处理。

扩展保存后必须区分“仍在插件队列”和“Web 已持久化”。网络中断、Web 未打开或回执未知时保留原操作并可幂等重试。扩展不后台扫描浏览历史，也不把自身队列描述为云端备份。

## 状态、错误与可访问性

- 加载使用稳定骨架，避免页面结构跳动。
- 同步提示不遮挡已经可用的本机内容；空闲页面不周期性请求整库数据。
- 媒体不可用时保留文本路径并解释原因。
- 破坏性操作使用明确、不同的确认文案。
- 桌面和窄屏均保持主要旅程可操作；主要动作支持键盘和可访问名称。
- 颜色不是表达成功、失败或选中状态的唯一方式；遵守 reduced-motion 偏好。

具体 DTO、数据库表、错误码、预算数值和 Provider 配置属于工程实现，不在本文冻结。
