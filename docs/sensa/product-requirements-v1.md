# Sensa Web 产品说明

本文定义当前生产 Web 的用户体验。领域术语与不变量由[领域文档索引](README.md)裁决，工程实现与发布方式见[工程说明](engineering.md)。

## 产品范围

当前产品由以下可共同交付的部分组成：

- React Web 应用；
- 同账号的浏览器阅读与采集扩展；
- 支撑账号、内容、学习、模型执行和同步的在线 API；
- 浏览器本机学习库与普通账号云同步。

原生客户端不在当前工作范围内。

## Web 体验约束

- 用户看到的是“内容、意思、学习、复习、练习和账号”等产品语言，不直接暴露内部领域术语。
- 页面只呈现真实数据和真实状态。内容未准备、保存失败、同步失败或服务不可用时，不显示可继续的假成功状态。
- 本机保存与云端同步是两个结果。本机事务成功后即可继续使用；同步状态单独显示并允许重试。
- 已开始的学习固定目标、方法、路线和历史。同一目标、语言方向与兼容内容来源显式发布或应用材料新版时，
  尚未操作的当前步骤与后续步骤可以采用最新版；已经发生的操作继续固定其当时材料，普通设置修改不能
  重写既有学习事实。
- 当前学习步骤只负责呈现和收集输入，不直接生成学习 Evidence、Completion 或调度结果。
- 活跃学习期间减少全局导航干扰；离开、中断和恢复必须保留明确语义。
- 页面通过标题、信息顺序、真实状态与行动层级表达主线，不以增加解释段落补救入口或结构含混。
  文案只承担内容、操作命名、必要状态、错误恢复与决策后果；不在任务页面常驻领域说明、使用教程或重复提示。

## 信息架构

公开品牌首页在尚无本机库的新浏览器中通过 `/` 展示，也可通过 `/welcome` 访问。已有本机库的浏览器通过 `/` 直接返回应用。首页以品牌故事为主线，
讲述生活经验、意义与另一种语言的相遇；具体入口、操作流程与学习包说明位于独立的
`/how-it-works` 页面。两页均支持中英文切换，并通过“进入 Sensa”衔接账号与应用体验。

```text
Web
├── 首页：开始或继续学习、到期复习
├── 我的语义世界：个人意义、收件箱、来源、详情与加入学习
├── 我的学习：已加入的目标、准备状态、学习记录与学习偏好
│   └── 内容入口：公开目录与已下载内容库各有独立页面
├── 自由练习：真实语境聆听与练习范围选择
└── 账号与设置：登录、同步、本机数据、服务和外观设置

浏览器扩展
└── 网页或字幕中的选区 → 解释/确认或保存待处理 → Web 内容与学习
```

首页是默认落点。主要行动是开始或继续当前可学习内容；到期复习是独立入口。没有可学习内容时，页面应引导用户从现有内容或个人表达开始，而不是展示不可用的学习按钮。

## 用户意图与产品交互层

产品围绕两条可以独立成立、也可以相互连接的主线组织：记录、整理和使用个人意义；学习、复习和持续积累。
保存一条意义不是学习的前置教程，学习也不要求先建立个人意义。用户可以只保存、只浏览、只下载或暂时停止。

用户表达目标，产品交互层负责组合必要的内部操作。默认路径不要求用户配置 Scope、Session、Run、材料版本、
来源成员关系或调度规则。已有能力必须保留，但不要求每项内部能力都拥有独立可见控件；测试通过模块接口
控制内部规则，不能为方便测试新增生产入口。

状态围绕用户正在处理的对象表达：个人材料区分未完成与已保存，内容包区分未下载、已下载与可更新，学习
区分待准备、可开始、可继续与后续复习。它们不是同一条“完成进度”；签到、下载数量或一次自评不能冒充
学习完成或掌握。数据读取未知或失败也不等于空库。内部版本、引用和修订只服务于相应操作，不成为日常
使用前必须学习的一套状态名称。

| 用户意图 | 默认路径与可见结果 | 相关能力的归属 |
| --- | --- | --- |
| 把遇到的意思留下 | 从原材料开始，澄清或手动填写，明确保存后能找回表达、意思和情境 | AI 是可选工具；Context 与接受事实不可省略；草稿不冒充已保存意义 |
| 找回、整理或使用我的内容 | 搜索或打开条目，查看原情境，按需修改、记笔记或加入学习 | 来源、修订和导出供相关任务查阅，不与内容主体竞争 |
| 找一本适合自己的词书 | 发现、查看、下载；准备学习时明确加入 | 版本和更新用于内容维护；下载不自动加入，加入不自动制造学习结果 |
| 开始或继续学习 | 当前内容与下一步在前；系统按真实可用状态选择任务并保存 | 只有一种可用方法时不要求选方法；未开始任务的默认计划由系统组织 |
| 今天先停在这里 | 离开后可找回原任务；明确结束时保留已发生事实 | 暂时离开、结束活动、声明已会不得互相代替；管理操作不制造完成或评分 |
| 暂时不学某项内容 | 在对应内容或管理入口调整后续学习，状态可查且能恢复 | 原内容、已经开始的任务和历史保留；不要求理解来源引用或范围修订 |
| 调整每天的学习量或学习内容 | 在相关偏好或内容管理中修改，能确认实际保存结果 | 内容安排影响下一条尚未开始的内容；数量影响后续活动，不重写当前学习或历史 |
| 回看进展或处理异常 | 查看真实记录，或在受阻对象旁处理具体问题 | 记录不是掌握度；资源、保存与同步失败提供相关出口，不默认展示诊断流程 |

操作层级按实际任务而非内部能力划分：核心意图进入主流程；偶发管理进入对应对象的二级操作；精细控制
只有在有明确用户需求时进入高级设置。纯系统、测试和诊断操作不进入正式用户界面。不能把所有复杂控件
搬进高级设置后宣称简化，也不能用常驻说明段落要求用户自行拼装流程。权限、费用、丢失数据等必须知情的
决定仍须明确呈现。

每条长旅程同时验收理解成本和操作成本：用户是否看得出当前对象与状态、下一步是否清楚、默认路径是否
多了无必要的选择、结果是否找得到、失败或中断是否能回到原目标。先用真实任务审查入口和状态，再核对
内部实现；功能正确、可靠性、性能和这些体验要求必须分别成立，不能相互替代。

## 页面职责与叙事

本节定义页面应支持的用户目标、阅读顺序与行动关系，是 UI 调整和体验验收的共同依据；它不表示这些要求
已经全部实现。完整业务分支与合法终态见[用户旅程](user-journeys.md)，本节不另定义领域状态或学习结果。

### 全局衔接与行动层级

首页负责“现在做什么”，我的语义世界负责“保存和理解我的内容”，我的学习概览和目标列表负责“管理已明确加入的学习”。
公开 Catalog 负责发现，已下载内容库负责本机拥有的包；拥有内容、接受意义、加入学习、资源准备和完成学习
分别呈现。用户只保存意义、只下载学习包或暂不学习，都是完整合法的停止点。
公开目录与已下载内容库可从首页或学习相关导航到达，但不合并进已加入的目标列表；两者之间的入口与
当前所在区域可辨认，导航归属不改变内容的拥有或学习状态。

各来源在明确加入后汇入准备、学习和长期复习主干。Book 不必绕经个人语义世界；Extension 和 Agent
投递的内容在 Web 中进入相应的个人意义或收件箱，不另建来源专属的学习入口。

- 每页围绕一个当前目标组织首屏和主要内容。主要行动可以是打开条目、输入、选择或确认，不要求每页
  都放一个醒目的按钮。同一决策的必要选项可以并列，例如评分选项；辅助查询、管理、偏好与导出不竞争主行动。
- 页面先呈现当前对象和任务所需的内容，再呈现相关状态与操作。筛选、列表或详情各有明确作用；数字、
  日历和来源元数据不能遮住当前对象或下一步。
- 已有导航或状态能够表达的信息不再加一段解释。空态只提供必要状态和与原目标相关的可用入口；搜索
  无结果先保留查询并允许修改筛选，不把用户转入注册、教程或不相干的新任务。
- 从列表进入详情，再返回时保留查询、筛选与位置；打开来源或参考资料后能回到原任务。状态变化后，
  当前对象与后续入口仍可辨认，不能只依赖短暂 toast 让用户猜测保存到了哪里。
- 一个无关服务失败不覆盖整页主线。阻止当前行动的失败就近呈现必要原因和恢复行动；影响数据安全或
  需要用户作决定时，保留明确确认与风险提示。

### 页面主线

以下描述行动语义，不冻结具体按钮字样、布局或 Skin。只读页可以以查看和返回为完整出口；未交付能力
不得呈现为可执行行动。已有用户能力不能为简化页面而被移除，但可以合并内部步骤、采用合理默认值，
或把偶发操作放回对应对象；不以保留能力为由把全部领域控制常驻首屏。

| 页面或工作区 | 用户来这里做什么 | 主要阅读与操作顺序 | 下一步或合法出口 |
| --- | --- | --- | --- |
| 公开首页、使用方式 | 判断 Sensa 是否适合自己并进入产品 | 品牌故事与真实能力；使用方式页说明必要流程；进入产品行动可找到 | 进入本机产品，不强制先登录或读完指南 |
| 首页 / Today | 开始或继续当前学习 | 当前任务与可用行动在前；当前路线的今日数量在后；浏览学习包、保存个人表达和管理学习作为辅助入口 | 继续原学习、开始可用任务、进入到期复习，或在无可学内容时选择来源 |
| 公开 Catalog | 找到适合自己的学习内容 | 搜索与语言方向 → Book 列表中的标题、内容摘要、方向和本机状态 → 详情 | 查看 Book；已有下载内容仍可访问，刷新目录不是浏览前置 |
| Book 详情 | 判断内容是否适合并决定下载或加入 | 标题与内容、语言方向 → 本机拥有和学习状态 → 对应行动；作者、许可与版本信息可查 | 未安装时下载；校验安装且路线匹配后才可明确加入；已加入后查看学习；更新为独立操作 |
| 已下载内容库、Portable 预览 | 管理已拥有的内容或确认导入 | 已下载 Book / 独立包 → 详情；选择文件后先显示内容、方向、作者、许可与冲突状态 | 确认安装或取消预览；安装后可另行加入学习、导出或主动应用更新 |
| 添加内容、按表达查找 | 选择学习来源，或从已有意义连接中选定一个表达 | 学习包／按表达查找／个人语义世界；直接查找按当前目标语言搜索本机已确认连接和已保存发布包，选中后展示意思与路线 | 明确确认加入；发布材料可用时进入学习详情，否则保留待准备条目并提供准备、停止或重试；不创建个人意义 |
| 我的语义世界 | 找到自己的意义，或保存新的材料 | 个人内容与搜索在前；创建、草稿与收件箱入口可找到；收藏、笔记和图谱服务于回看 | 打开已接受意义的详情，继续草稿或处理收件箱；不强迫加入学习 |
| 收件箱 | 处理一条尚未确认的材料 | 原材料摘要、来源和已有事实 → 当前需要补全或确认的部分 → 对应行动 | 继承原材料继续澄清、明确接受或丢弃；关闭后仍保留未完成项 |
| 新建、记录场景与澄清工作区 | 把真实经历说清楚并找到相应表达 | 直接输入或继续已有材料 → 对话与候选 → 独立确认；原材料和来源按需查看 | 保存已接受意义或保留草稿；错误时保留输入并重试，不另开无来源副本 |
| 已接受意义、表达与义项详情 | 回看这条表达的意思与个人情境 | 表达、义项与 Context 是主体；来源、笔记、资源和修订可查；学习状态与可选加入行动相关联 | 回到原列表、修订个人情境或明确加入学习；已接受内容不默认重开澄清 |
| 我的学习 | 找到已加入的内容、继续学习或处理准备问题 | 当前路线的内容与真实状态 → 查看或处理具体内容；记录、数量和偏好按任务进入 | 进入学习或准备任务；词书与其他内容的后续学习管理是辅助任务，不默认先填写模式和范围 |
| 学习目标列表与详情 | 找到一个目标并判断如何继续 | 表达、意义、来源与真实状态 → 与该状态相符的行动；方法和记录供核对 | 开始或继续、处理准备失败、复习或重学；未到期可查看已保存的后续安排 |
| 初次学习、复习与重学运行时 | 完成当前学习任务 | 当前任务类型与步骤 → 实际材料及输入或评价 → 保存反馈与推进；参考工具按需打开 | 保存后进入下一步；中断可恢复原 Run；真实结算后显示结果和可用后续行动 |
| 学习记录与统计 | 回看自己实际做过什么 | 当前范围与筛选 → 初学、复习、重学的真实记录 → 对应目标 | 查看目标或返回我的学习；数量不被解释为掌握度或长期学习效果 |
| 自由练习、范围选择与聆听 | 围绕所选内容进行当前已交付的真实语境聆听 | 当前练习范围 → 表达选择 → 实际语流播放与控制；范围选择保留具体内容身份 | 暂停、切换、重试或返回；未交付的完整听说读写活动不构成可执行入口，不显示正式学习完成 |
| 账号与设置 | 处理一个账号、数据或配置目标 | 设置目录 → 所选任务的状态与表单 → 保存、测试、同步或数据操作的真实结果 | 返回目录或原任务；登录、同步、备份、本机清除、账号删除保持独立 |
| 只读参考、例句与来源 | 解决当前表达或材料上的具体问题 | 被查询的表达与语境 → 实际释义、例句、发音或来源 → 返回 | 回到原任务；收藏、笔记或已支持的加入学习是显式可选行动 |
| 内容运营区域 | 核对候选内容是否可交给发布流程 | 候选内容与身份、语言方向、成员、版本、digest → 真实校验结果；公开内容清单辅助核对 | 验证候选或返回；不把本机校验命名为已经公开发布 |
| 无效详情、页面错误与恢复页 | 找回原任务或选择可行出口 | 明确区分加载、不可用、找不到与失败 → 与原目标相关的恢复或返回行动 | 可重试时重试，否则返回来源或首页；不显示空白页或伪造空库 |

### 首页的状态主线

首页依据真实任务状态确定行动层级，不按固定模板同时放大“开始、继续、复习、添加和管理”。

| 当前状态 | 主内容与行动 | 辅助入口与限制 |
| --- | --- | --- |
| 本机必要状态尚未读取完成 | 稳定加载状态 | 不显示确定的零、空库或可开始状态；已有可用本机能力不等待无关在线请求 |
| 有可恢复的学习 | 原任务类型和必要身份 → 继续原任务 | 当前路线切换不得重绑该 Run；其他路线的新增与管理任务保持独立 |
| 没有待继续任务，有可开始内容 | 当前路线的可用任务 → 开始 | 到期复习保留独立入口；分派按实际计划，不由 UI 编造队列或新内容数量 |
| 只有到期复习或可进入的重学 | 相应任务类型 → 进入该任务 | 不用“新内容”名义启动复习或重学，不人为创建到期状态 |
| 已加入内容，但所需资源未就绪 | 目标的真实准备或受阻状态 → 查看相关目标或任务 | 任务或尝试失败显示实际原因，与等待、缺少能力分别处理；不可显示可开始的假 Ready |
| 尚未加入可学内容 | 找到第一个学习来源 | 公开内容与个人表达均可进入，使用清楚的行动层级，不先要求配置模型或登录 |
| 今日没有剩余可用任务 | 如实呈现当前计划状态 | 允许查看学习、浏览学习包或保存个人表达；不因队列为空推断所有目标已掌握，也不强迫新增 |

多种状态可以共存。可恢复任务优先保持连续性；其他情况依据实际计划与可用任务呈现，单个目标的准备
或任务失败不能掩盖其余可学习内容。若有多项可恢复任务，“继续”须指向可辨认的固定 Session/Run，其他
任务仍可从对应目标找到，不静默替换本次继续的对象。恢复任务的原路线与首页当前路线不同，需用简短的
语言方向标识让用户辨认，不通过额外教程解释内部绑定规则。

### 加入、准备与运行的连续性

- Book 详情和内容库分别显示真实下载、加入及更新状态。发现新版和下载新版是辅助维护任务，不能使
  已加入内容的学习入口消失；应用更新仍是独立明确操作。发现和下载允许跨路线，加入则以内容校验、
  原子安装和当前路线精确匹配为前提；不匹配时给出相关路线选择，不能隐式改绑或重标内容。
  已加入状态按对应路线呈现，其他路线的已加入事实不能冒充当前路线已有可学内容。
- 保存意义或安装内容后，结果在对应列表或详情中可见；加入学习仍是可选后续行动。加入成功后显示
  对应路线的已加入状态与实际准备状态，并能进入该目标或任务，不要求用户再寻找一次入口。
- 准备中可查看真实任务，并保留已支持的停止或恢复行动；失败时就近显示原因与可行的重试、配置或
  原文件重选入口。失败信息来自实际任务或尝试，目标仍呈现当前学习目的的真实准备、就绪或受阻状态。
  仅涉及某个 Provider 的问题回到相关配置，不把用户送入整个设置目录寻找。
- Ready 后由明确学习行动进入 Runtime。步骤、评分和完成仍以领域提交结果为准；保存失败时保留当前
  材料与输入，先恢复保存，不推进到下一步或显示完成。
- 普通离开 Runtime 不等于完成，返回产品后可继续未被明确中断的原任务。用户明确“声明已会”等改变
  继续资格的操作按相应合法终态呈现；撤销声明不自动恢复 Run，需用户再次明确启动。查看参考、编辑
  “我的场景”或将场景存入个人意义都是当前学习的辅助分支，返回时仍接续原步骤，不另建竞争的学习任务。
- 完成页只呈现实际结算结果，以及当前确实可用的继续或返回行动。后续复习按真实安排出现；没有安排
  时不编造日期，不把一次初学完成表述成永久掌握。

### 必要文案与体验验收

操作标签应说明对象和行动，状态标签说明真实结果。说明文字只有在帮助用户完成当前任务、修复错误或
判断操作后果时才出现；不在每页重复“如何使用”“保存不等于学习”等定义，也不为每个入口默认配副标题。
下载、已加入、准备中、可开始等区别应由真实状态和不同操作表达。数据删除、丢弃未同步修改、权限与
费用等决定仍须保留必要披露，不能以减少文案为由隐藏后果。

页面主线的验收关注：用户能从标题、内容和行动判断当前位置，能找到下一步，能确认结果所在位置，并在
中断或失败后回到原目标。真实状态、内容与操作共同提供证据，不要求用户读一段解释才能完成任务。
窄屏、键盘、界面语言和 Skin 切换保持同一主线、内容身份、行动层级与恢复能力。

### 学习管理的操作归属

- 我的学习以已加入内容、实际准备状态和继续入口为主体。每日数量与偏好是相关设置，不要求用户先完成
  一组配置才看得到内容；已固定且没有可选替代的方法不呈现成必填选择。
- 默认页先显示学习内容与真实记录；“管理学习内容”按需打开词书和单独加入内容的管理，签到日历作为
  记录后的辅助入口展开。关闭管理或日历不改变内容、计划或学习事实，重新打开读取实际保存状态。
- 词书的暂停、恢复与后续学习范围属于对应词书的管理任务；单条内容的后续学习选择属于对应内容。来源
  重叠、成员 revision 和范围快照由系统处理，不要求用户先解决这些内部问题才能开始正常学习。
- 生成资源、停止准备、重试与使用既有材料只在当前对象确实需要时出现；个人场景使用、外部服务权限和
  费用保持必要确认。资源明细、更新与导出是辅助任务，不与已就绪内容的开始行动并列成为必经步骤。
- 签到记录到访，学习记录呈现真实学习事实，计划用于未来任务。三者可以查看，但日历、手动签到或计划
  编辑不能成为空学习页的主要行动，也不能使用户误以为签到已经完成了今日学习。

## 核心旅程

### 本机启动与账号连接

用户无需注册或登录即可进入产品并建立本机库。公开学习包的安装、正式学习与复习、个人材料草稿、
本机设置以及加密备份在本机库中可用；浏览器资料的持久性和导出入口必须清楚可见。Sensa 托管模型、
账号同步、远程 Intake 与 Sensa 托管 AI 需要账号；扩展的本机阅读与采集不需要账号。用户自填且在本设备执行的模型连接可在未登录时使用。
没有模型时，未完成的个人内容保留为草稿或待处理资料，不能呈现为已经澄清、生成材料或完成学习。

登录账号前，已有本机库立即可用。连接账号时先检查云端资料：云端为空，可将当前本机库连接该账号；
本机只有新建的空库且云端有资料，可在应用外壳打开后于后台恢复。两边都有资料时停止自动连接，保留
两份原始数据，提示先导出本机备份；用户明确清除本机库并重新连接后，才可在这个浏览器恢复云端库。
不同账号不能自动认领已有账号的本机库。新设备在云端恢复完成前不能把尚未到达的资料显示成确定的零；
正常后台恢复/同步的进度与失败在账号与设置的数据区域呈现，并提供重试入口。首次账号连接尚未核验
云端或新设备尚未恢复时，账号资料保持未知；预检的 HTTP、网络或权限失败不能把空本机投影改为权威零。
初次未恢复的事实页面呈现恢复状态与明确重试，设置仍可访问，不启动学习规划或展示空清单。已有真实
本机事实或已确认 checkpoint 的设备继续使用本机事实，不被无关在线预检失败阻断。
该初次未知状态不同于日常后台同步，不为正常同步增加全局横幅。

### 语言设置与当前路线

用户在“账号与设置 → 我的语言”维护一条或多条学习路线。每条路线只表达“我正以哪种支持语言学习哪种目标语言”，并拥有自己的每日新内容数量；它不声明用户的母语、会哪些语言或熟练度。界面语言是独立设置，切换界面语言不得改变学习路线、内容语言或学习进度。

每日数量保存中的操作状态和保存失败在原偏好面板可见；未收到回执时先重读实际数量，不自动重放或把不确定结果说成保存失败。修改数量不改变已经开始的 Run、步骤、材料或已发生记录。
尚未保存数量时，首次点击开始直接使用默认每日新学上限 20，并与开始操作一同保存；不弹首次数量确认，也不要求选择唯一已固定的方法。
已有数量始终保留，用户仍可在偏好中主动修改；开始失败不能留下半完成设置。学习偏好不展示当前不可选择的固定学习方式或单选项控件。

路线可选不代表已有可开始的学习内容。路线列表分别显示本机已安装且目标／支持语言精确匹配的学习包数量，以及默认个人内容语音是否已配置；语音已配置不代表某个资源已经准备成功。缺少资源时保持明确的未就绪状态，不跨语言借用内容或语音。

Web 与浏览器扩展的界面语言支持简体中文、繁体中文、英语、日语、韩语、西班牙语、法语、德语、巴西葡萄牙语、意大利语、俄语、印尼语、越南语、波兰语和土耳其语。Web 优先使用用户保存的界面语言，首次访问按浏览器语言选择；扩展按浏览器语言选择。已支持的区域变体归入对应界面语言，未支持的变体按明确的回退规则处理；界面语言不改写学习路线的语言标签。

Web 与浏览器扩展分别保存各自当前使用的路线。Web 中切换路线会改变后续加入学习、包选择和首页学习队列；扩展中切换路线会改变后续网页解释、翻译、写作和采集。两边读取同一组路线，但一边的临时选择不应抢走另一边正在使用的路线。

暂停或归档路线后，它不再出现在新的操作入口中；已有学习记录和已经开始的会话仍保留原路线事实。修改路线的支持语言也只影响之后创建的内容与会话，不能重写已经生成的材料或历史。

切换路线后可以继续原 Run 的固定步骤；完成与结束原 Run 不依赖新路线已经确认每日数量，也不把原 Session 自动续入不同路线。结束保存失败时保留结果页和重试反馈，不以返回首页掩盖失败。

### 外观与官方皮肤

用户在“账号与设置 → 外观”从 Sensa 策展并随当前产品版本交付的 Skin catalog 中选择完整皮肤。
每套 Sensa Skin 可以形成明显不同但内部一致的页面空间布局、responsive presentation、颜色、字体、
形状、层级、图标、插画、组件视觉配方以及受约束的密度、装饰与动效。Skin 可以把同一组页面区域
呈现为单栏、分栏、sidebar 或 dock，但所有 Skin 仍使用同一信息架构、route identity、必须存在的页面
能力、业务流程、真实数据、操作语义、逻辑阅读/焦点顺序和无障碍行为。产品不提供任意第三方 Skin
代码的运行时安装；外部创作只有经过 Sensa 的设计、代码审查与产品发布治理后，才会成为可选择的
Sensa Skin。

Skin、`light | dark | system` color mode 与文字大小等阅读偏好是相互独立的本机外观选择。切换 Skin
立即作用于当前界面，并保留其他外观选择、route、导航位置、未提交输入、焦点意图和进行中的学习/
练习状态；它不能改变
材料披露、评价、Evidence、完成、调度、保存或同步结果。系统级无障碍设置优先，颜色不能成为成功、
失败、选中或可操作状态的唯一信号。所选 Skin 在当前版本不可用时，界面回退到完整可用的默认 Skin，
不得因此修改或丢失用户数据；已随应用交付的 Skin 在离线启动时仍然可用。

### 个人内容

首页“添加个人内容”入口可选择手动创建、对话澄清或先保留场景材料，不把记录个人内容直接等同于调用 AI。
关闭选择或编辑后回到原任务；已消费的入口动作不在返回页面时自动重开。三条入口复用已有接受和草稿流程，
不新增独立的意义模型。

“我的语义世界”提供 Sensa 自身的对话入口。用户可以像进入普通对话一样直接发送文字或图片；移动端
图片选择允许从图库添加或拍照。用户也可以保留原有“记录场景”方式，先把文字、图片和熟悉表达存成
草稿，再继续澄清。当前澄清入口只支持文字与图片，不承诺音频、视频或语音输入。

空白进入、记录场景后继续，以及从收件箱打开不完整 Intake，都进入同一个澄清工作区。后两者预先携带
已有材料、来源和候选事实，而不是启动另一种流程或复制一份无来源草稿。澄清由同一个有界教师 loop
完成：模型在每个用户回合先作为语言老师理解并自然回应，同时在该回合的最终输出中判断 Context、Sense
和 Expression 是否清楚。这个判断与候选是模型最终输出的隐藏结构，不是工具调用；产品不要求用户点击
额外的“整理”或切换到抽取模式。界面只呈现对话、已经稳定的候选和必要的真实工具状态，不展示模型
隐藏推理。

所有回合遵守同一种对话协议，没有“首轮模式”和“后续抽取模式”。模型能直接回答时使用自身语言能力，
不得为了填满工作台而检索或生成候选；只有三项都清楚时才同时给出完整候选。唯一的澄清工具是按需读取
用户本机已有语义，用于判断复用关系，而不是代替自然回答或模型本身的语言判断。
确认后的 Context 只描述用户材料所支持的现实情境，不包含“怎么说”“英语叫什么”等元语言请求，也不把
澄清对话拼接成场景正文；原始材料和对话作为来源与构造记录单独保留。

用户经过澄清后明确接受 Context–Expression–Sense 关系。
Inbox 保留完整原文、已有表达／意思和来源，图片可展开查看；媒体不可用时不能用图片数量冒充已成功呈现。
已具备完整事实的材料用明确的“确认保存”完成接受并打开结果，不通过点击意思正文隐式接受；未完成项可手动补全或继续澄清。
手动补全直接继承原项的已知事实，并可从本机已确认意思中查找、查看场景与边界后选择复用；选择只是编辑草稿，
最终保存仍须明确确认。未改写的原意思保留解析来源，手写的新内容不借用模型 provenance；复用固定到用户查看的版本。
原图和原始捕获独立保留，不用修订后的 Context 冒充原文。已有合法图片定位时不要求虚构文字 Context。
关闭／刷新保留本机填写草稿；原材料变化后旧填写不能静默覆盖，须重新核对，明确选择从最新材料重新填写。
丢弃前确认具体材料及未完成澄清，取消不修改数据；失败仍保留材料和可重试出口，不影响其他条目。
用户已明确知道意思时，也可以从“添加内容 → 手动创建”自行填写情境或原句、原文中的表达、表达语言、
意思与典型使用场景，无需配置或调用 AI。表达原形可与原文词形不同，但必须定位到真实 Context 中的一次出现；
重复出现时由用户选择。只有点击“确认并保存”才创建完整 Personal Meaning，来源如实记录为 learner-authored。
关闭或恢复编辑草稿不表示接受；保存后进入普通表达详情，不创建独立裸 Sense，不自动加入学习。
缺 Context、Expression、Sense 或接受事实的内容保留在收件箱，不冒充已经确认的 Personal Meaning。
调用方已经给出 Context 时，接收端不再判断它“够不够好”，也不因当前学习路线不包含该语言
而拒绝采集。

Sensa Web 内的模型和工具只能提出或修订候选。即使候选已经完整，仍必须由用户在独立的确认动作中接受后，
应用的本机 authority 才能写入 Personal Meaning；Web 澄清 Agent 无权自动保存、自动加入学习或制造学习结果。

已确认内容在“我的语义世界”中以确认后的 Expression 作为主标题；点击后进入表达详情，而不是重新进入
澄清 Agent。详情可以查看来源、Sense、Context、图片、笔记和学习资源，并可修订 Context；修订创建新版本，
不覆盖原始接受事实。修改内容与“加入学习”是不同操作；接受一个意义不会自动创建学习进度。用户从
“我的语义世界”点击“加入学习”时，系统把当时 Web 的当前路线固定到这次课程成员关系中；之后切换路线
不会把它悄悄搬到另一条路线。
个人内容详情的二级操作提供收藏、笔记和删除。删除将内容移入回收站，从默认列表和新增学习选择中
移除，但保留原情境、接受事实和来源；既有学习目标、记录、调度、笔记和个人学习场景不级联删除。
回收站可查看原内容并明确恢复同一身份，恢复不复制条目、不重新接受 Sense，也不允许旧离线副本
自动恢复。删除项只读；删除与恢复都以用户正在查看的版本为依据，过期操作必须重新核对。
笔记编辑以实际读取的保存版本为依据；另一页面或设备已更新正文时，保留当前草稿并展示最新笔记，
由用户明确选择使用最新内容或保存自己的版本，不能静默覆盖。清空笔记同样防止旧编辑器恢复已清空的正文。
详情的“更多”提供“修改意思和表达”：用户先看到当前真实情境，再编辑表达、意思与典型使用场景并
明确保存。它纠正同一条个人意义的当前连接；原接受与情境历史仍可追溯，不改写公共 Sense 版本或既有
学习历史，不自动加入新目标。编辑期间原内容变化时保留草稿，必须明确重新读取并审阅最新情境；
重读保留已输入的表达、意思和典型场景，随后仍需确认保存，不能直接覆盖。
同步若只调整内部事实记录的排列、未改变已审阅内容，不应要求用户重新审阅；另一设备的独立笔记修改也不作 Context 修改处理。
被替换的解释在“过去的意思和表达”中只读查看，不与当前解释混在一起，也不重开旧澄清任务。
多段情境及图片的顺序在保存、同步、纠正和重开后保持一致；详情、纠正审阅和学习来源读取同一材料组合。
场景编辑的图片数量和原图大小限制须与界面提示一致；拒绝超限或不支持的文件时保留已输入文字和已保存来源，用户可改选有效图片继续保存。
原解释的收藏和笔记仍能从相应列表找回；旧笔记始终编辑原 Sense，不转移给修改后的意思。一个 Meaning
有多个已确认意思时，列表入口必须定位被选中的意思，不能默认打开另一条连接。
学习包中的实际内容即使尚未存入个人语义世界、尚未评分，也能从收藏和笔记找回原内容；回看不创建
Personal Meaning 或学习结果。学习连接按实际目标保留表达与学习状态，不因共享同一个 Sense 合并掉
另一条目标。收藏、笔记和例句的读取中或失败状态不显示成已确认的零条，失败提供重读出口；详情中的
收藏动作须先取得当前状态，不能以空缓存或历史操作回执判断当前是否收藏。
当前轻量主线默认提供意思收藏和笔记；尚无公开新增入口的空例句收藏不在默认界面展示。已有例句收藏
保留原数据和可用的回看、取消入口；读取中或失败不能按零条收起。来源暂不可用时保留记录并显示读取风险，
同一列表的其他可读收藏仍可使用，不补造例句或学习状态。轻量例句收藏的新增入口保留待建设。
公共 Sense 的版本、拆分和关系审查保留待建设；个人意思与表达的纠正不代表该公共审查能力已经交付。

用户也可以在已连接的 Agent 对话里完成澄清和整理，并说“把这几个表达存到我的语义世界”。外部 Agent
不复用或遥控 Sensa Web 的澄清界面；它在自己的会话中形成 Context、定位后的 Expression 与已解析 Sense，
再通过同一 Intake 边界提交。Agent 的当前会话已经得到用户明确保存请求时，连接调用本身构成 one-shot
delegated acceptance，Sensa 不再要求用户对同一条内容二次确认。三项事实完整时走快轨，确有缺失时进收件箱。

用户在“账号与设置 → Agent 连接”选择 Codex、Cursor、Claude Desktop、Windsurf 或 CLI，并创建
约十分钟有效、只能消费一次的安装码。复制的安装命令不含长期凭据；安装器直接向 API 兑换后，把凭据写入
本机私有配置并登记 MCP adapter。Codex 同时安装 managed Skill；其他 MCP 客户端可通过同一 MCP prompt/
tool 说明获得 Context–Expression–Sense 格式、来源与回执语义。Skill/prompt 类似领域命令说明，不是用来替
Sensa 检查事实是否完整的运行时验证器。

浏览器扩展不参与 Agent 连接、鉴权或交付。设置页显示连接的有效/过期/撤销状态、到期时间、最近使用时间、
近期生命周期审计，并提供原子更新、撤销和本机卸载命令。更新安装只有在新安装码成功兑换后才撤销旧连接；
每个连接默认每小时最多提交 120 个新的 operation，完全相同的幂等重试不重复计数。页面不展示内部 library id。

Agent 先获得“已排队”回执，这只代表 Sensa 云端已经持久接收。用户的 Web 在登录且
联网时取回队列，本机库实际提交后才变成“已存入”，并带回“已进语义世界”或“已进收件箱”。
断网、Web 未打开或本机确认丢失时保留同一 operation 幂等重试，不把“已排队”说成“已存入”。

### 加入学习与资源准备

用户明确选择内容加入学习。系统固定学习目标、当前路线和可用方法，在 Web 应用后台静默准备、校验并冻结所需资源。生成不打开聊天窗口，切换页面不取消任务；用户可查看状态或停止准备。关闭 Web 后不保证继续执行，重新打开后可以主动恢复。资源失败或不完整时保留可恢复状态，不创建可开始的假目标。

轻量学习先建立／回想经验，再进入表达绑定空间。第二张卡连接书写形式、主要声音、当前意义、
经验绑定说明与同场景的目标语言表达。使用框架按需要提供，补充例句和已有合格词源渐进展开；
资源详情展示实际保存材料。普通例句不能自动冒充第一张卡的场景实现。

当前 Web 产品允许使用 approved Support Language 文字场景完整实现第一张卡的经验内容。没有图片不代表
资源缺失、学习包不可用或路线未就绪，界面也不应为尚未制作的图片保留空占位；如果存在图片，它用于
增强同一经验，而不是补足文字场景的表达能力。依赖视觉、无支持语言或低识字等学习方式不属于当前 V1
的隐含 fallback，未来若支持，必须通过明确的产品与 Profile 定义引入。

个人资源 Agent 根据已固定的表达、义项和资源范围调用工具，获取并保存准确声音和可靠来源事实。
勾选使用自己的场景时，原始图片和文字进入任务；图片直接作为第一张卡资源，文字可以忠实精简或改写。
未勾选时不注入个人场景，第一张卡使用明确的教学场景。绑定说明和同场景例句始终围绕第一张卡经验。
声音由 provider-neutral 的客户端接口提供，Web 当前默认使用 Edge TTS adapter；替换 provider 不改变
学习流程、资源合同或 UI。无可用的准确声音时明确报告材料不可用，
不能标记就绪。模型按已解析的适用范围与资源合同提交候选；可选模型审核查看整个资源组合，
确定性校验始终执行。词源等语言事实只接受已固定的可靠来源，不由模型自行认证。
该 Agent 的成功产物是当前 learner 的 On-demand Materialization，不是 Published Package；生成或更新
个人材料不会自动创建 `.sensa`。只有用户明确选择导出/分享时，才从选定内容快照构建 Portable Package，
且不携带学习进度、Evidence 或调度。


从内容包加入学习时，包的目标语言和支持语言必须与当前路线精确匹配；不匹配时说明原因并要求用户切换路线，而不是把内容标成另一种语言或隐式回退。同一个稳定学习目标可以出现在多条路线中并共享记忆进度，但每条路线保留自己的来源、支持语言、材料和每日计划。

学习包中心使用三个明确的用户区域：`/catalog` 展示所有语言路线的公开 Book，
`/catalog/:bookKey` 提供可分享的稳定详情地址，`/library` 只展示当前资料库实际保存的 Book 与独立
`.sensa`。Catalog 不把每个版本显示成另一份书；Library 也不能把尚未下载的目录项伪装成用户拥有的内容。
页面先展示本机缓存，登录和打开页面不等待目录网络请求；目录在距上次检查超过约六小时后低频后台刷新，
用户也可以手动刷新。发现新版只显示真实更新状态与作者提供的变更摘要，不弹全局提示，也不自动下载
或改变学习计划。目录允许跨路线发现和下载；只有加入学习时要求与当前路线精确匹配。

`/publisher` 是仅向服务端授权 subject 返回的内容运营区域。未授权账号既看不到入口，也不能通过直接
URL 获得发布能力。当前区域提供公开版本清单与本机 `.sensa-book` 候选验证；真正发布仍由受保护的仓库
release workflow 完成，浏览器不持有对象存储或 Registry 提升凭据。

Book Version 通过 `.sensa-book` 一次分发；内嵌 Manifest 固定有序成员及每个 `.sensa` 的
identity/version，外层摘要固定整本书的精确字节，不定义另一种可执行学习内容格式。下载完整校验 Book
archive 与全部 Portable 成员后原子保存到本机。首次加入与新版
“应用更新”都需要用户明确操作；下载完成不等于已加入或已更新。应用新版后，新增条目进入未来学习，
删除条目退出未来计划；身份未变的目标保留原进度与复习状态。更新不增删已开始 Run 的 participant；
兼容材料更新可以刷新尚未操作的当前 Step 和后续 Step，已经操作的 Step 保留当时材料。Sense 或表达
Binding 身份变化时按新目标处理，旧目标和历史不被删除。

Sensa Official 策展内容、外部作者内容和 learner 明确导出的可复用内容使用同一个 `.sensa` 交换合同；
Official 身份来自 Catalog/Registry provenance，不由文件自报。用户也可以从本机选择 Portable
Lightweight Package。选择文件后先显示只读预览，包括标题、
语言路线、目标表达、意义、作者与许可；预览不得安装内容或创建学习事实。用户明确确认后才保存到本机，
保存后仍需另行“加入学习”。包的路线与当前路线不匹配时允许保存，但不能在当前路线加入，界面应明确
提示切换路线。已安装 Portable Package 可以重新下载为 `.sensa`；同一 `packageId + version` 的相同内容
重复导入是幂等操作，不同内容不得静默覆盖。Portable 内容通过公共 Runtime 门禁即可使用，不因此获得
官方审核或发布身份。更高版本安装后显示为待应用更新；应用仍需用户明确操作。Sense/Binding identity
未变时继续使用原 Learning Target、Retention Target 和学习进度，并把新版作为当前材料；已经操作的
Step 保留当时材料，当前尚未操作的 Step 与后续 Step 使用新版。identity 改变时创建新目标，旧目标不因
新版缺少它而自动删除。Portable Package 是导入载体，不把永久版本链或旧包历史回放暴露为产品模型；
界面也不把旧版本重新加入解释为一次隐式降级。

学习 Package target 的首次经验步骤允许用户添加或编辑“我的场景”（文字与图片）。场景按当前
Learning Target + Route 保存，下一次打开立即显示；学习包提供的必需经验资源仍保留为发布内容，
个人场景以清楚标识的私有 scaffold 呈现。编辑只生成新 revision，不改写已经操作的 Step，也不产生
Evidence、完成状态或调度变化。

读取场景时区分加载中、读取失败和确实没有场景；失败提供重读出口，不把已有内容显示为不存在。
场景编辑从实际保存内容开始；另一页面已更新时保留本机草稿，显示最新场景，并由用户明确选择使用最新
内容或保存自己的版本。失败重试检查同一次保存，不重复追加场景；已提交但列表读取失败时不误报写入失败。

表达揭示后，已有个人场景时显示“存入我的语义世界”。该按钮是一次明确的 direct Semantic
Acceptance：使用 Package 已固定的 Sense Version、target Binding 与当前 scene revision 直接创建完整
Personal Meaning，不进入澄清流程，也不创建第二个 Learning Target。场景后续有修改时显示可再次更新，
未修改时只显示真实的已存入状态。学习来源和 Personal Meaning 的删除、更新与进度互不级联。
若语义详情里的情境已被用户独立替换，再次存入学习场景保留其现有整理，并在同一意义追加本次场景；
后续更新只修改这一新增场景，不重复追加，也不复活已退役素材。

未开始且支持多种方法的目标可以选择学习方法；已经开始的目标继续原方法和历史，不做静默迁移。不同方法可以有不同步骤，但共享相同的目标、事实和调度边界。

### 学习与复习

当前 Web 的正式学习交付主线是轻量学习及其复习／重学。Structured 高保证的领域模型和本机运行分支
保留为待建设能力；公开内容接入及其完整用户流程尚未交付，不以内部注入能力数据的测试认领产品完成。

词典与参考例句是只读查阅。已开始材料的点词保留确切句子、片段和材料语言方向，不因另一标签页切换路线查成另一语言；进入参考例句再返回保留当前查询，关闭词典回到原学习步骤，不自动保存意义、加入学习或评分。确认未查到和服务不可用分别呈现；主动重新查询可以恢复。独立判断题在提交主要回答前不提供题面点词、词典菜单或快捷键，进入反馈后才可查阅。
当前公开 Web 词典使用在线 provider 的 prototype 结果；固定可下载 Reference Release 与离线索引尚未交付，不能把在线查询验收认领为该能力已完成。
当前 LJ-14 按在线查询、只读来源与原任务返回闭环收口；固定离线词典明确保留为待建设，不作为该在线主线的关闭门槛，也不随之认领完成。
学习目标的来源查阅保留其实际发布版本，不因共享内容属于另一册、或新版已下载而打开错误来源；只读来源页不提供加入或应用更新动作。正常词书管理入口仍可明确下载、加入或更新。
轻量学习表达揭示后，可从“更多”原位查看当前材料的来源，再返回同一学习卡；不要求切回材料路线，也不暂停、重新加入或改写当前步骤。来源查询不在揭示前提供。
公开来源缓存缺失不表示词书或学习记录不存在；来源查阅显示读取失败，并保留返回原任务的出口，不猜测其他版本或自动重新加入学习。在线词典断网失败后仍可返回原卡，重连后由用户明确重查。
查词时分别保留词条、来源定义和辅助语言gloss的真实语言；来源英语定义不因为查询西语词条而改标为西语，也不被模型辅助释义覆盖。词条发音仍属于该表达的语言。

学习界面复用正式运行时、卡片、工具栏、笔记、场景、词典、例句、音频和偏好能力。开始一次会话时，
系统固定路线、支持语言、学习意图与每日新学上限；每条 Run 只固定实际选中的目标、方法、课程来源和材料基线，
不为进入第一条内容冻结整个学习库。修改词书、范围、补充来源或未开始目标的方法，影响下一条尚未开始的内容；
已开始的 Run、步骤、记录与已提交的方法不变。用户随后切换当前路线时，正在进行
的会话仍按原上下文继续。个人材料发布兼容新版（例如补充自己的图片），或 learner 显式应用同一 Portable
来源的兼容新版时，尚未操作的当前步骤立即刷新，后续步骤也使用最新版；已经提交操作的步骤仍按当时
材料重放。每一步保存成功后才能前进，刷新、暂停和重新打开应恢复同一运行及其逐步材料事实，而不是
重新生成内容。

到期复习只处理已经进入 retention 的目标，不引入新内容。一次复习最多产生一次有效结果和一次调度更新；失败后的修复或重学不能重复结算原复习。
轻量再学习仍未连上时，界面保留“还需再学习”的真实未完成状态，不显示成功完成或满进度；
用户明确选择“再试一次”才为同一目标继续独立 Run，也可以返回首页后找回。成功再学习保存独立记录，
不改写触发它的 Review Outcome，也不重新初始化或再次推进该次复习的 FSRS。

### 轻量学习的揭示资源与学习问答

Expression 和 Sense 已确定后，第二张卡按“资源目录 → 表达适用范围 → 准备 → 展示”组织内容。
资源目录采用发音、释义、用法、例句、辨析、构词、词源、助记八类；类型矩阵和判断规则统一见
[揭示资源目录 v1](sense-learning-resource-model.md#111-揭示资源目录-v1)，本文不维护另一份清单规则。
表达本身是主体，释义保留与第一张卡经验的连接，例句包含同场景表达。折叠展示不改变资源身份；
不把“按需补充”作为类别外的独立产品流程，不要求用户申请后才能确定适用范围。
内部区分不适用与适用但未就绪；第二张卡仅展示实际就绪的合格资料，缺少资料的区域整体隐藏，
不留空标题、占位、失败说明或申请补充按钮。必需资源未就绪时仍不能开始学习。默认展开内容不等于资源全集。当前材料、学习记录与进度不会因
调整展示偏好而改变；内容更新遵守既有材料版本规则。

揭示阶段提供 AI 学习问答入口，围绕当前表达、义项、经验和已采用资源回答具体问题。
它是可选交互而非资源类别，适合换词、场景应用、结构解释与造句反馈等长尾需求。
提问不打断当前学习；没有提问、离线或对话服务不可用不妨碍使用已有学习资源。
回答不自动写回 Sense、正式资源或学习结果；其他义项与推测应明确区分。
该入口属于本版产品定义，尚未实现的能力不得展示为已可用。

### 学习中声明已会

学习过程中选择“声明已会”后保存可撤销的 learner declaration，并继续当前语言路线中的
下一个可学习目标。没有下一个目标时留在学习流程内展示空队列状态，由用户主动返回。
该操作中断原 Run 的规划资格，不把它伪装成完成，也不制造评分、掌握或调度事实。

### 自由练习

当前 Web 的可执行练习主线是真实语境聆听，包括范围与表达选择、实际语流播放和必要的失败恢复。
自由练习围绕系统内表达材料组织，而不是正式学习目标。材料来源和练习方式分离；个人表达或已下载词书中的
表达无需先加入学习。当前只有聆听一种方式，不新增方式确认步骤；从已选表达进入时直接开始。YouGlish 只接收
表达文本与实际表达语言；语义详情、完整 Context、学习状态和调度不是前置条件。来源与选择采用轻量引用，
列表按页读取并支持搜索，不先加载全部表达详情或生成全部下拉选项。相同语言与形式的表达不按多个 Sense
重复计数；当前播放表达保持稳定，来源变化后的下一次选择须重新核验。范围选择与恢复失败不静默换成其他材料。
选择整个来源时使用该来源当前可用的表达；自选部分材料时保留表达引用，不为“全部”生成全量成员快照。
返回后再次进入聆听继续原表达；明确重新选择材料时才重新开始。恢复时原表达不可用须提供重新选择或重试，不静默换词。
已打开的聆听按所选表达的实际语言检索，不因其他标签修改当前路线而换成另一语言。播放器准备、播放和速度以供应商实际事件为准；切换表达或口音退役旧播放器，旧字幕及状态不能进入新查询。嵌入播放器保留供应商的实际高度，不强制压缩或裁切其画面。
完整听说读写活动、即时反馈与练习历史属于后续能力，交付前不呈现为可用行动。自由练习不写入正式学习
Evidence、Completion 或 FSRS 调度；练习中发现的内容只有经过用户明确保存，才进入个人内容流程。
默认练习页只列已交付活动，不以禁用卡片展示未建设的活动。当前内容为空时可以直接浏览学习包或添加个人内容，不必绕回首页；不制造样例或可播放状态。

### 账号与数据

账号页区分：本机资料库、登录会话、云同步、数据导出、清除本机数据和删除账号。退出登录后本机库仍可在
当前浏览器使用，但账号在线服务停止；清除本机数据不等于删除云端副本；删除账号需要在线重新确认。
清除后重开保持空本机库，后台启动、联网和自动重试不能重新拉回旧云端资料。用户明确点击现有同步／
重连入口后才可恢复；失败保留这个选择，成功应用资料与对应基线后恢复普通后台同步。清除后新增的本机
资料仍受身份冲突保护，明确同步也不能静默覆盖。
未连接账号的本机备份可恢复到空的未连接本机库；账号备份只恢复到原账号的空本机库。已有备份版本仍可读取。
已有本机资料的线索却读不到库身份时，不得当成首次使用创建空库或展示零进度。默认进入独立恢复入口，
用户可以重新打开或明确选择备份；错误密码、账号不匹配和恢复期间新增资料必须拒绝恢复，不覆盖现有内容。
身份缺失的空目的地也可明确恢复。账号备份仍要求原账号的当前登录，恢复后重新打开再进入正常使用。
没有可用副本或用户明确放弃本次恢复时，可确认“重新开始”：另建独立本机库并退出当前账号，旧文件和草稿
保留，不清空、覆盖或自动迁入新库。此动作不表示原资料已恢复；新库初始化失败仍提供重新打开与恢复出口。
设备库选择信息损坏也进入恢复，不猜测原库位置；明确重新开始时保留损坏信息和所有原文件。
原标签页停止读写并提示重开；新库不继承旧库的未确认草稿、对话、练习选择或签到，外观偏好仍为设备共用。

同步冲突、未同步修改和删除中的状态必须可见。用户数据不能因为重新登录、刷新、重复请求或另一设备恢复而被静默覆盖。

普通操作只在本机即时保存，并标记新的本机内容版本；不逐操作上传。存在待同步版本时，应用在停止
操作约两分钟、连续使用约五分钟、完成一次学习会话、页面进入后台或重新联网时形成一次批量
Checkpoint；回到前台只在上次云端检查已超过约五分钟时拉取。用户可以在本页“立即同步”。没有
待同步版本且云端检查未过期时不发起整库请求。

正常同步不显示全局横幅或顶部浮层。全局提醒只用于长时间无法形成 Checkpoint、退出或清除本机资料
会丢失待同步版本，以及新设备恢复明确失败等需要用户决策的情况。Remote Intake 是独立投递邮箱，
空邮箱或一次网络失败不能被描述成“已有内容仍在队列”。

账号辅助恢复的云端备份是已确认的后续能力，但当前版本不提供备份开关、历史恢复点或恢复流程。
现有账号同步只能按同步状态展示，不能命名为“已备份”。未来只有完整上传并校验通过的不可变
恢复点才能显示备份成功；首发恢复方式是账号辅助，零知识备份可在未来作为另一模式增加。

## 浏览器扩展

扩展无需账号即可开启阅读模式、识别语言、使用站点规则与本机朗读，并将原文采集暂存在扩展，交付给同一浏览器中打开的本机 Web 资料库。解释、翻译和句中意义判定需要 AI：用户可以在扩展本机配置自己的兼容模型服务，无需 Sensa 账号；使用 Sensa 托管 AI 与账号同步则需要登录。没有可用模型时，原文仍可保存为待处理资料，不能显示为已解释或已确认意义。

自带模型的 API Key 保存在浏览器的扩展本机存储中，设置页不回显，内容页面也不能读取。扩展只在用户为具体模型地址授权后连接该地址。自带模型的请求直接发给用户选择的服务；连接测试可能产生该服务的费用。

扩展只在用户开启阅读模式或主动操作时读取当前页面。它可以从普通网页和可用字幕中取得选区、上下文和来源，提供解释、原位确认或保存待处理。

视频阅读尊重播放器实际选中的字幕轨；未选择时可使用可用原始轨，不强制改成英语。字幕语言取自轨道或用户文件，不继承视频网站界面语言。切换句子、文件、视频或恢复原文会取消过时翻译，旧结果不得返回当前阅读面。直播不支持、字幕不可读取与数据超过完整加载上限分别显示真实原因，不把截取的部分字幕声称为完整加载。

用户在插件中点击“登录 Sensa”已经表达了连接当前 Web 账号的意图。若同一浏览器已有有效的 Sensa
Web 会话，授权必须自动完成并返回插件，不再要求重复登录或再次确认连接；只有 Web 会话不存在时才
进入登录，登录成功后继续同一笔短时授权。授权不得把账号令牌放进页面 URL，也不得转移另一账号或
另一资料库尚未送达的材料。

扩展保存后必须区分“仍在插件队列”和“Web 已持久化”。网络中断、Web 未打开或回执未知时保留原操作并可幂等重试。游客采集队列与已有账号队列分别保存；资料库不一致时停止交付，只有用户明确重新连接后才能改绑，不能随登录自动迁移或丢弃。扩展不后台扫描浏览历史，也不把自身队列描述为云端备份。

阅读、解释和写作使用扩展当前路线。普通阅读把页面中识别出的原文语言作为本次输入、把路线的支持语言作为输出；如果页面偶尔出现第三种语言，只改变这些片段的输入语言，不修改当前路线，也不把第三种语言记成用户会的语言。写作则从路线的支持语言生成目标语言表达。

术语表按精确的“原文语言 → 译文语言”方向保存；反向使用必须有另一条记录，不能自动把条目倒过来。术语表属于学习者的本机库，在“账号与设置 → 我的语言”旁边维护：学习者在 Web 端写一次，阅读面按发布后的副本使用，扩展不提供第二份可编辑的副本。术语表只影响用词，不改变意思，也不承诺模型每次都照做；产品界面不得把它描述成定义、学习进度或已保存的翻译。

阅读模式里可以整页朗读：按文档顺序逐块朗读，每块用它自己的语言（按块判断，一页可以引用第二门语言），正在朗读的块高亮并滚动到视野内，停止即清除。容器与可编辑区域不朗读；没有可朗读文字、语言无法确定、设备没有对应声音三种情况必须分别给出原因。朗读只用设备本机语音，不产生网络请求；学习者可以在设置页从本机音色中指定一个，指定音色只在其能发音的语言下生效。
学习者也可以在网页的输入框里写自己的语言，用同一个快捷键（`Alt + T`）得到目标语言的表达。这是唯一反向的请求（其余功能都是把读到的内容变成熟悉语言），只有学习者真的会写句子的输入框会被读取：密码框与不可编辑的框永不读取；译文先显示、由学习者决定是否替换输入框内容，未替换前原输入保持不变。使用 Sensa 托管模型时，该请求与阅读共用账号额度；自带模型由用户选择的服务处理。
预览期间继续编辑会取消旧答案；字段后来变为受保护或原文已变化时，不用旧预览覆盖新内容。
学习者可以对某个站点说“不在这里”。这条规则在页面上和插件弹窗里都能写，范围为当前站点（不是当前标签页），页面内写入后立刻停止该页阅读；规则生效期间该站点不再被自动注入、工具栏按钮不再开启阅读，解除入口必须在插件弹窗里可见。

语音、参考、翻译或渲染能力必须按精确语言标签解析。产品只允许三种真实结果：精确支持、明确展示的兼容变体回退、不可用；不得为了让按钮看似可用而静默改用英语或把内容重标为另一种语言。

## 状态、错误与可访问性

- 加载使用稳定骨架，避免页面结构跳动。
- 正常同步不占据全局界面；空闲页面不周期性请求整库数据。
- 媒体不可用时保留文本路径并解释原因。
- 破坏性操作使用明确、不同的确认文案。
- 桌面和窄屏均保持主要旅程可操作；主要动作支持键盘和可访问名称。
- 颜色不是表达成功、失败或选中状态的唯一方式；遵守 reduced-motion 偏好。

具体 DTO、数据库表、错误码、预算数值和 Provider 配置属于工程实现，不在本文冻结。
