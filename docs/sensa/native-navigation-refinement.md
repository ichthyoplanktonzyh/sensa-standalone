# 原生主路径与信息层级调整

日期：2026-09-10。范围：Web 本地执行前的原生体验优化，第一轮主导航与内容浏览。

## 体验决定

参考正式 `apps/web/src/experience/components/ContentScreen.tsx`、`HomeScreen.tsx` 和 PRD §5，
让页面直接呈现用户内容，减少模块入口菜单。没有采用 `apps/web-next`，没有更改领域模型。

- 首页保持开始/继续、只复习，以及材料和个人采集两类入口。收紧标题、计数、面板和段落间距。
- 我的内容直接嵌入词义世界；已保存、收件箱、已移除、搜索和保存操作无需先打开另一层页面。
  同页可切到学习材料，完成搜索、导入、查看具体意思和显式加入学习。
- 我的学习集中显示学习状态、学习范围、准备任务和历史；不再承担材料目录。
- 内容页保留图文关系、采集接入和准备工具；已有独立词义世界路线仍可从首页使用。
- 材料从逐项大面板改为紧凑列表。统一减小标题、页面留白和面板圆角，保留触控目标尺寸。
- 词义世界工具与内容共同滚动，列表按需构建，避免短窗口、大字号和软键盘压缩内容区。
  空搜索结果与尚未保存内容分开提示，嵌入时不重复显示壳层的状态消息。

学习执行仍通过既有 Flutter → Rust → SQLite 路径。语义确认不自动加入学习；Focus 可空；
首次完成和调度交接仍由内核原子提交。没有修改用户库、Profile 执行规则、Web 或同步。
