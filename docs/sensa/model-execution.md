# 统一模型执行层

更新：2026-09-11。本地实现与替身验收完成，未部署云端。

## 已确认边界

Sensa 默认模型服务统一使用 Genkit。Web、浏览器插件和原生端继续通过
Sensa API 使用默认服务；客户端不依赖 Genkit 的内部数据结构。自定义服务
保留本机直连，用户密钥不随新模型配置上传 Sensa。模型执行不接管语义接受、
学习资源校验、入学或运行时结算。工具调用仍由既有领域 loop 执行和裁决。

## 实现

- `packages/contracts/src/sensa/modelProtocol.ts` 保存版本兼容的图文与工具请求协议。
- `packages/contracts/src/sensa/modelExecution.ts` 提供有界队列与仅含运行元数据的记录。
- `packages/model-runtime` 隔离 Genkit 1.42.0 和 OpenAI 兼容适配器的依赖。
  默认 agent、阅读/语义解释和旧材料供给入口均使用该包。Genkit Flow 的输入输出
  只含请求编号、用途、模型和用量；密钥、私人图文、模型结果放在请求局部上下文，
  不作为 trace 内容。兼容适配器处理图文、JSON、工具和阅读流式输出。
- 服务进程默认并发 2、同服务商 1、待执行上限 64、总等待/执行期限 45 秒。
  `SENSA_MODEL_CONCURRENCY`（1–16）和 `SENSA_MODEL_PROVIDER_CONCURRENCY`（1–8）
  可调整。交互请求优先，等待中的生成任务随时间提升优先级。429/502/503/504
  非流式请求最多重试一次；流式不自动重播，资源修正仍由原有 loop 决定。
- Web 的默认/自定义请求共用设备队列。高级设置支持直接获取服务商模型列表、
  更换模型，并显示当前页面会话的排队、耗时、状态、token 和默认服务追踪编号。
  不支持列表的兼容服务仍可手填模型。模型列表可用不代表图像/工具能力已验证。
  自定义密钥仅保留页面内存；持久化与备份只含非密钥配置。
- 原生直连增加设备并发 2、每服务商 1、等待上限 64；排队最多 45 秒，执行仍
  使用既有 HTTP 超时。取消后的排队任务不会调用模型，但会在出队/排队超时时
  才完成取消。原生未新增执行历史 UI。

## 当前限制和待决策

服务端并发限制作用于单个进程/Edge isolate，不是跨实例的全局供应商配额。
运行记录由服务日志和 Genkit trace 元数据提供，没有部署集中监控或持久化管理台；
失败请求仍有请求编号，但客户端不保证收到失败 trace 编号。Web 活动只覆盖当前
页面会话，不代表全部设备/账号的使用量。

插件旧版阅读设置原本把密钥加密存到服务端。不自动导出、搬迁或删除这些
密钥；Owner 已于 2026-09-11 确认插件迁移暂不处理，继续保留旧配置兼容。插件现有服务请求
已经进入统一 Genkit 执行层。不能将此旧路径描述为本机直连已全面完成。

## 验证入口与边界

常规模型执行验证入口：`npm run sensa:model-execution-smoke`。

`npm run typecheck`、`npm run build`、`npm run lint`、本地国际化扫描、备份和服务
状态 smoke 通过。真实 Genkit Flow/兼容适配器搭配合成 fetch，在 Node 和 Deno
验证图像、工具、JSON、流式输出、token/trace、重试与并发；Edge 入口依赖检查通过。
原生队列测试与编辑文件静态分析通过。隔离浏览器验证完整个人内容/学习资源流程、
模型列表与选择、密钥不上传和刷新清除、中英文与窄屏布局。没有调用付费模型。

这些证据不代替真实供应商验收或 Edge 托管运行验收；云端仍需既有 CI/CD 发布。
