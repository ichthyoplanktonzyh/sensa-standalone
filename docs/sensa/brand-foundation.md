# Sensa 品牌基础

> 状态：Owner-confirmed brand foundation  
> 更新日期：2026-09-16

本文回答 Sensa 为什么存在，以及这种信念应如何进入品牌表达和产品设计。它不是领域模型的替代品，
也不把已确认 Logo 自动扩展为完整品牌色、UI 字体或宣传语。领域对象和不变量仍由
[`../../CONTEXT.md`](../../CONTEXT.md) 及领域文档裁决；本文负责把其背后的人本动机表达为可以被用户
理解、被设计延续的品牌基础。

## 1. 为什么创建 Sensa

一个已经建立母语或其他既有语言能力的人，并不是带着空白的头脑学习另一种语言。

人在自己的生活中先拥有经验、感受、意图、判断和对世界的理解，又在既有语言共同体中学会用符号
进入、唤起和表达它们。开始学习另一种语言时，learner 通常不是第一次知道雨、河流、请求、遗憾或
亲密，而是不知道另一个语言共同体怎样辨认和表达这些意义，也还不熟悉相应 Expression 的声音、
形态和用法。

传统语言学习很容易把这个顺序倒过来：先给出陌生符号，再用翻译、定义和重复要求 learner 记住它。
这种方法把人当作等待装入词条的容器，忽略了 learner 已经拥有一个由真实生活形成的意义世界。

Sensa 从相反的方向出发：先让场景和经验唤起意义，再揭示另一种语言中的表达，并帮助这条连接在
真实使用与长期记忆中稳定下来。

## 2. 核心品牌命题

Sensa 相信：

> **你已经拥有一个世界。**

学习另一种语言，不是重新从零学习世界，而是让一个已经形成的个人世界与另一个语言共同体理解、
切分和表达经验的方式相遇。

这场相遇包含三种同样重要的变化：

1. **辨认与连接**：learner 已经清楚知道某个 Sense，只需要学习另一个语言共同体如何自然表达它，
   并把陌生的音、形和用法连接到已有经验。
2. **澄清与成形**：learner 拥有具体场景和“我知道自己指什么”的经验结构，却暂时无法在母语或
   其他已知语言中找到准确表达。Sensa 帮助 learner 定界这个 intended meaning，使它成为可以被
   共同理解并连接到 Expression 的 stable Sense。
3. **发现与扩展**：另一种语言可能突出 learner 过去没有单独命名或留意的意义区别，使原有经验被
   重新看见、重新组织，而不是简单换上一组标签。

因此，Sensa 既不把第二语言学习简化为逐词翻译，也不假设 learner 对目标意义一无所知。learner
不是空杯，而是带着自己的世界进入另一种语言。

## 3. 从经验结构到可学习的表达

learner 有时不仅不知道目标语言怎样表达，也无法立即在母语中找到一个准确词语。此时最先存在的
可能是一段能够重返的场景、一种感受、参与者之间的关系、动作方向、因果结构或尚未说清的表达
意图。learner 知道“我指的是这个”，但这个意义还没有被充分外化和定界。

日常品牌语言可以把这一阶段描述为尚未成形的 sense；在 Sensa 的正式领域语言中，它还不是稳定的
`Sense`。`Sense` 专指已经能够被语言共同体辨认、引用和复现的意义区别。此前的个人经验结构与
intended meaning 必须保留为 Context、Personal Meaning、Personal Anchor 或必要时的 Meaning Focus，
不能被一个模型猜测的词直接替代。

Context 因而不是在单词之后补充的装饰例句。它固定“谁在什么情况下指什么”，约束参与者、状态、
方向、因果和意图，使相近但不同的意义不会因为脱离场景而被混为一谈。Sensa 可以在这个基础上帮助
learner 澄清边界、形成 teaching-sufficient 的 stable Sense，再找到或构造与之兼容的 Expression
Binding。

```text
可重返的 Context + 尚未充分表达的 intended meaning
                         ↓ 澄清与有效接受
                 stable Sense Version
                         ↓ 连接
                    Expression Binding
                         ↓
              可被正式学习和长期保持的连接
```

正式学习不能把仍在变化的私人感受、一个孤立的词或模型临时生成的解释当作稳定目标。只有 intended
meaning 在具体 Context 中得到足够定界，并形成 stable Sense 与目标 Expression 的明确连接后，Sensa
才能让 learner 稳定地建立、检查、强化或恢复这条连接。

这条 personal-first 路径解释了为什么 Sensa 同时需要 Context、Sense 和 Expression。它不表示每一次
Book、Catalog 或 reviewed stable-Sense 学习入口都必须重新提交个人 Context；当 stable Sense 与目标
Binding 已经存在时，learner 可以直接进入学习，但学习对象仍然是具体的 Sense–Expression 连接，而
不是裸词或翻译等号。

## 4. 公共 Sense 与个人经验

一个 Expression 所承载的 Sense 必须保有语言共同体能够共同辨认、讨论和复现的边界；否则语言就
失去共享理解的基础。但同一个公共 Sense 在不同人心中可以拥有完全不同的经验形状。

“河流”可以让一个人首先想起家附近的小河，让另一个人想起洪水、航行或地图上的大江。一个人也
可能早已知道“海洋”的定义，却直到真正站在海边，才让这个符号获得尺度、声音、气味和情感。

所以 Sensa 同时尊重两件事：

- 公共 Sense 使人能够与语言共同体相互理解；
- Personal Meaning 与 Personal Anchor 使这个 Sense 在一个人的生活中真正有根。

个人经验不替换公共 Sense 的身份和边界。产品可以让 learner 自己的场景取代通用教学场景，成为
理解、回忆和表达的主要入口；如果 intended meaning 确实越过已有边界，则应被辨认为另一个 Sense，
而不是把公共 Sense 悄悄改写成私人定义。

## 5. 品牌承诺与产品方法

Sensa 的品牌信念、承诺、方法和期望转变保持以下关系：

- **信念**：你已经拥有一个世界。
- **承诺**：让难以言说的意义获得形状，让另一种语言进入你的世界，也让你通过它重新看见世界。
- **方法**：从场景和经验出发，先唤起并澄清意义，再揭示或共同找到表达。
- **转变**：原本只能感受到、只能用熟悉语言表达或尚未被准确说出的经验，成为 learner 可以通过
  另一种语言理解、保留和表达的连接。

“你已经拥有一个世界”是当前品牌命题的核心表达，不等于已经批准的市场宣传语。最终文案可以随
媒介和语言调整，但不能退回“更快背单词”“AI 帮你翻译”或“收集更多知识”等不符合 Sensa 初衷的
叙事。

## 6. 一套围绕真实世界运转的系统

Sensa 不是某一个 Web 页面、浏览器扩展或 Agent，也不由任何单一客户端定义。完整的产品由三个彼此
连接的部分组成：接触真实世界的入口、属于 learner 的个人语义世界，以及进入正式学习与复习的学习
运行时。三者共同服务于一条持续发生的循环，而不是把生活与学习分割成两个空间。

### 接触真实世界的入口

意义首先发生在产品之外。learner 会在阅读网页、观看字幕、参与对话、回想经历或试图说清一种感受
时，遇到值得理解、保存和表达的内容。入口的职责是在这些时刻靠近 learner，保留必要的 Context 与
表达意图，并把它们带回 Sensa，而不是要求 learner 先进入一个学习界面，再想象一个脱离生活的例子。

当前已经确认的入口包括浏览器扩展和 Agent。它们只是第一批接触面，不是 Sensa 的边界。未来，入口
可以随真实生活发生的场所扩展到手机等更多设备与情境；这些属于完整产品图景，不应在当前页面上被
描述为已经交付的功能。

### 属于 learner 的个人语义世界

从入口带回的内容不会被压缩成词条、翻译或收藏链接。它首先作为 learner 能够重返的 Context 和
Personal Meaning 被保留，再逐渐形成清楚的 Sense，并连接到另一种语言中的 Expression。这个持续
生长的结构，就是 learner 的个人语义世界：它记录的不是“收集了多少内容”，而是一个人怎样在自己
的经验中辨认意义，又怎样与另一种语言共同体的表达建立联系。

个人语义世界为不同入口提供连续性。无论内容从哪里被带来，也无论之后通过什么界面重新遇见，真实
来源、意义边界、接受事实与学习状态都不能被界面猜测或改写。

### 进入学习与复习的运行时

当 learner 准备好，并明确选择某条稳定的 Sense–Expression 连接进入学习后，学习运行时负责让这条
连接被看见、听见、使用、检查和再次遇见。它依赖真实保存的内容与状态，不制造已经理解、已经学会
或已经同步的结果，也不把尚未定界的私人经验直接包装成正式学习目标。

学习运行时不是这条路径的终点。新的表达最终要回到阅读、倾听、交谈与真实生活中；下一次真实相遇
又可能带来新的 Context、新的意义区别和新的表达，使个人语义世界继续生长。

```text
真实世界
  ↓ 遇见、记录、带回
接触外界的入口
  ↓ 保留 Context 与表达意图
个人语义世界
  ↓ learner 明确选择进入学习
学习运行时
  ↓ 学习、复习、使用
回到真实世界
```

因此，入口是可扩展的接触层，个人语义世界是跨入口延续意义的核心，学习运行时是稳定已选择连接的
实践空间。Web、浏览器扩展与 Agent 是这套系统在当前阶段的具体形态，但任何一个都不等于 Sensa
本身。

## 7. 品牌故事

人并不是在学习另一种语言时才第一次拥有意义。

我们早已通过生活认识世界，也早已在自己的语言中学习怎样辨认、记住和表达它。新的语言面对的
不是一片空白，而是一个已经有河流、气味、关系、分寸、愿望和回忆的世界。

有时，我们知道自己想表达什么，只是不知道另一个语言共同体会怎样说；有时，另一种语言又会让
我们发现，熟悉的经验还可以用不同的方式被划分和理解。还有一些时候，我们甚至无法在母语中找到
准确的词，只拥有一段场景、一种感受和“我指的是这个”的确定感。

Sensa 从这个相遇开始，并出现在意义实际发生的地方。网页里让人停下来的句子、对话里没有说完的
意图、字幕中的一种表达，或记忆里尚未说清的感受，都可以从不同入口被带回属于 learner 的语义
世界。那里保留的不只是一个词，而是它从哪里来、为什么重要，以及它究竟连接着怎样的意义。

当 learner 准备好时，清楚而稳定的连接才进入学习与复习。新的表达在那里被听见、看见、使用并
再次遇见，直到它能够离开学习界面，重新回到阅读、倾听、交谈与生活中。下一次真实相遇又会继续
丰富这个世界。

所以，Sensa 的故事不是把人带离生活去积累更多符号，而是在真实世界与学习之间建立一条可以往返
的路：人先生活，然后遇见意义；Sensa 把重要的片段带回、澄清并连接；学习使连接稳定；新的语言再
回到生活里，逐渐成为一个人理解世界和表达自己的方式。

## 8. 对设计的约束

品牌设计应当同时传达：

- **经验感**：意义来自真实生活，不来自抽象词条堆积；
- **辨认感**：从模糊到清楚，从“我知道这个意思”到“原来这样表达”；
- **成形感**：尚未被准确说出的经验在具体 Context 中逐渐获得边界和表达；
- **打开感**：已有世界向另一种语言开放，并因新的意义区别得到扩展；
- **人的主体性**：产品帮助 learner 建立连接，不替 learner 宣称经验、理解或学习结果。

品牌不应被塑造成通用的词典、翻译器、学校课程、记忆打卡工具或 AI 助手。书本、脑、聊天气泡、
国旗、翻译箭头和 AI 闪光等惯用符号不能仅凭行业联想成为核心身份。

Sensa 品牌 UI 基础色已经确认：Forest `#2E3A2F`、Sage `#7A8A73`、Stone `#C9C3A7` 与 Paper
`#F6F4ED`。它们分别提供深色文字与主要行动、沉静的辅助组织、温暖的结构分隔以及默认页面底色。
组件悬停、选中、面板、边框与深色模式可以从这四个锚点派生经过对比度验证的色阶；成功、警告和
错误继续使用独立的状态色，不能为了统一品牌色而混淆真实状态。

Quiet 是这组基础色在默认产品界面中的直接表达。Clear 仍是 Skin 体系中的另一种策展呈现方向，可以
拥有自己的完整语义色板，但不能把自己的配色宣称为新的 Sensa 品牌基础色。Skin 的差异不改变固定
Logo、产品语义或数据状态。

Sensa Logo v1 已作为固定品牌身份独立确认：开放式主体、右上独立形状及轮廓化 `Sensa` 字标使用同一组
冻结路径，Skin 只能选择已导出的 color、ink 或 reverse 呈现，不能重画、重新排字或用滤镜换色。Logo 的
生产渐变与品牌 UI 基础色是两个受控层，确认 UI 色板不会重新着色 Logo。完整图标体系、字体、图像语言
和声音仍需在本基础上分别探索并批准。
