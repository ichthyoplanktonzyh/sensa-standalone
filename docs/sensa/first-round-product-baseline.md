其他推荐按当前方案推进，有遗漏时通过具体用例补充。本文件记录首轮产品范围、可见状态和
用户操作，不增加第三条领域主旅程，不替代 PRD、领域模型或未来 API/Sync 合同。

- [current-stage.md](current-stage.md) 裁决近期交付范围；[PRD](product-requirements-v1.md)
  定义产品 IA，本文件是其首轮执行清单。
- [个人语义世界模型](personal-semantic-world-model.md)裁决采集、收件箱、Semantic Acceptance
  与完整 Personal Meaning；学习身份和运行规则仍由其余领域文档裁决。
- 本文件沿用已确认的行为意图，正式布局、组件、插件交互形态和具体 API 错误码在 M0-2/M0-3
  定义。新增插件的细节是下述可调整的实施默认，不声称已经经过浏览器或用户走查。

首轮以文字为主，中文 familiar language、英语 target language，正式学习只开放 lightweight。
用户可以从现有内容、应用内材料或浏览器采集开始；选词书不是全局使用前提。首次正式学习
仍须有合法 Study Plan、Target 与 ready materialization。2026-09-07 补充确认：首次须确认
每日新学数量，目标就绪后沿用回首页开始。

## 2. 首轮能力清单

| 编号 | 能力区 | 首轮交付内容 | 主要阶段 |
| --- | --- | --- | --- |
| P01 | 账号与首次使用 | 受邀登录、账号与当前会话、首次必须确认每日新学数量后才能开始学习；允许从现有内容或自己的材料开始 | M1 |
| P02 | 首页与今日学习 | 开始/继续 Mixed 学习、次要 Review-only 入口、真实数量与准备状态；无目标时显示两类开始入口 | M1 |
| P03 | 现有学习内容 | 少量已审核 Book/Catalog、具体意思与表达详情、加入学习；不要求宽覆盖词典或高级搜索 | M1 |
| P04 | 我的词义世界与收件箱 | 应用内文字捕获、草稿/收件箱、必要时澄清、确认完整意义、查看来源、撤销误收与显式加入学习 | M2 |
| P05 | 我的学习 | 已加入目标、来源、准备状态、唯一合法继续动作、每日额度、primary Target 的“我已会”声明 | M1–M2 |
| P06 | 首学、复习与重学 | 经验提示、主动回想、揭示与 learner rating，完成后进入保持；到期复习、遗忘恢复和中断继续 | M1 |
| P07 | 学习记录与基本偏好 | 实际完成/复习记录、下次复习信息；真实可用的口音、译文显示和自动播放等基本设置 | M1–M3 |
| P08 | 同步与数据控制 | 待同步状态、重试、安全退出、本机清除、导出、账号删除与旧设备写入屏障 | M1–M4 |
| P09 | 浏览器采集插件 | 在网页原位捕获文字与上下文、检查来源、解析/确认或保存待处理、回到 Web 继续，并可显式加入学习 | M2，M3/M4 验收 |

产品范围中的九个能力区不等于九个页面。浏览器插件是 Personal Semantic World 的外部入口，
与 Web 共用身份和 Semantic Intake authority，不创建第二套词义库存、学习进度或调度。

2026-09-07 owner 修订：首发允许开放自由练习、词典、统计、签到；它们仍须按资源、
真实数据、恢复与权限条件验收，不把“允许”写成“已生产交付”。九个原能力区保留，
练习/词典作为现有相关页面能力，统计归 P07，签到作为独立活动事实，不另建路线图。
签到和练习均不得产生正式 Evidence、学习进度或调度；统计不得据此推导掌握。
首轮仍不要求高保证学习、全部练习 Activity、全量词典资源、个人集合/完整笔记管理、
复杂诊断或额外签到激励。现有笔记和场景编辑保留；连续天数细则待确认。未交付的主入口隐藏，原型仍可保留用于验证后续能力。
首轮仅一种学习方式，不显示无实际选择的 Policy 选择器；目标详情如实说明当前方式。
图片/语音/OCR、移动分享、桌面全局采集及更多浏览器覆盖后续交付。

## 3. 浏览器插件首轮边界

**实施默认**：先以桌面 Chrome 为目标浏览器。具体支持版本、安装/更新渠道、权限实现和
受限页面清单在 M0-2/M0-3 核实；不据此承诺 Edge、Firefox、Safari 或移动浏览器兼容。
受邀版必须有普通测试用户可完成的安装与更新路径，不能只有开发者本机可运行的插件目录。

首轮交互要求：

1. 用户主动选取网页中的词、短语、句子或文本片段，通过插件入口捕获。上下文可以先没有
   明确 Expression；后续再圈定，不把整段任意文本自动当作一个已确定的表达。
2. 预览选中文本、必要的句段上下文、页面标题/来源 URL 和采集时间。保留固定 Context 与
   Expression occurrence 定位；网页更新后仍能重返当时的材料，不能只保存一个活链接。
3. 允许用户修正或补充上下文；抓取不完整、没有权限或页面不支持时明确说明，并可转为用户
   主动粘贴。数据范围围绕此次采集，不后台扫描浏览历史或自动上传整站内容。
4. “保存待处理”只接纳 Intake/Inbox，不启动语义确认或学习；“解析这个意思”表达另一个
   明确意图，可调用受约束的解析/构造能力，不把模型建议冒充用户接受。
5. 快轨：信息充分时，在插件内呈现 Context、被定位的 Expression 及候选 Sense/Binding；
   用户确认完整结果后保存 Personal Meaning。有效确认不要求再跳回 Web 重复一次。
6. 慢轨：缺少表达、义项不确定、需要深入对话或用户主动延后时，保存到同账号收件箱，并提供
   “在 Sensa 中继续”。首轮复杂多轮澄清由 Web 承接，不要求插件复制完整应用。
7. 保存结果显示“已进入收件箱”或“已保存到我的词义世界”。后者可提供单独的“加入学习”
   意图，沿同一 Curriculum/Policy/readiness 链处理；保存成功不等于可以立即开始学习。
8. 登录过期、断网、重复点击、插件重启和账号切换均保护待提交采集；操作幂等且绑定原账号。
   插件只处理采集与交接，不持有服务端模型密钥或写入正式学习派生状态。

首轮默认由用户逐次主动采集与确认；持续 Agent 委托、自动批量采集不在本次必交范围。
领域仍允许具有明确授权的 delegated acceptance，后续开放时遵守同一 authority/provenance
合同，而不是另造“插件自动确认”特例。

## 4. 主流程状态矩阵

以下是用户可见状态，不是一份可直接复制到数据库的总 status 枚举。语义完整性、学习成员、
内容 readiness、Runtime、调度与同步分别有自己的事实；页面组合这些事实决定可执行操作。

| 编号 | 场景 | 可见反馈与操作 | 保存/恢复要求 |
| --- | --- | --- | --- |
| S01 | 首次进入，没有学习内容 | 从现有内容开始，或记录自己想表达的意思；可了解插件入口 | 不强制选词书，不进入空 Runtime |
| S02 | 材料已保存，尚未解析或接受 | 收件箱/草稿，修改、解析、继续或稍后处理 | 可以长期保留；未完成材料不是稳定 Personal Meaning |
| S03 | AI 正在处理 | 处理中；可离开后返回 | 保存请求和结果身份，重试不重复创建事实 |
| S04 | 有 Sense/Expression 候选，尚未确认 | 接受、修正或继续讨论；Focus 仅在需要时出现 | 候选与已确认事实分开，不自动确认 |
| S05 | Sense 已确定，表达或 Context 仍不完整 | 显示待补齐项，允许继续或延后 | 保留草稿/Inbox 与已有合法事实，不提前创建完整成员 |
| S06 | 完整意义已确认，尚未加入学习 | 展示 Context、表达、意思与来源；可加入学习或仅保留 | 接受与 Add-to-Learning 独立，重复请求幂等 |
| S07 | 已加入，内容准备中 | 说明准备中，可离开或学习其他目标 | 保留成员与同一准备任务，不显示可成功的开始入口 |
| S08 | 内容准备失败/当前不可用 | 原因、可用的重试或修正动作 | 保留已确认语义和学习意图，不要求从头捕获，不静默降级 Policy |
| S09 | 内容就绪 | 开始或继续学习 | 只使用当前计划固定的合法材料 |
| S10 | 学习中途离开 | 说明保存位置，可继续或结束本次活动 | 已提交回答保留，未完成部分不伪造成完成 |
| S11 | 首学或本次复习完成 | 本次结果与后续安排，可返回或继续 | 服务端确认后展示权威结果；重复提交不重复结算，不宣称掌握 |
| S12 | 复习暴露遗忘 | 需要再学，可现在恢复或稍后继续 | 保留原 Review 结果，重学不重新初始化或改写它 |
| S13 | 当前无候选 | 区分已完成、额度已满、无到期内容、准备中、计划不可用 | 根据具体原因给出添加、等待、重试或结束动作 |
| S14 | 相同目标已在学习中 | 已加入，并显示真实准备/学习状态 | 保留合法来源，不重复创建进度；不把不同 Context 的采集简单合并 |
| S15 | 用户声明“我已会”或撤销声明 | 展示用户自己的声明及继续动作 | 不伪造 Evidence、完成或 FSRS 更新；跨设备冲突可恢复 |

## 5. 插件采集状态矩阵

| 编号 | 场景 | 可见反馈与操作 | 保存/恢复要求 |
| --- | --- | --- | --- |
| E01 | 未安装/尚未绑定账号 | 安装说明或登录 Sensa，完成后回到采集 | 已捕获的临时材料不因登录跳转无提示丢失 |
| E02 | 无选区、页面受限或 Context 不完整 | 明确说明，重新选取、补充或主动粘贴 | 不伪造全文读取、来源或 occurrence 定位 |
| E03 | 已捕获，尚未发送 | 预览原文、上下文和来源；修改、保存待处理或请求解析 | 只处理此次明确操作的数据范围 |
| E04 | 正在解析/提交 | 显示进度，可离开后返回 | 插件关闭/重启后可查同一请求；重试使用稳定 operation identity |
| E05 | 缺表达/义项不确定/待确认 | 保存到收件箱，在插件补齐或到 Web 继续 | 不显示成已进入稳定词义世界，不自动加入学习 |
| E06 | 完整结果待接受 | 在原位展示当前 Context–Expression–Sense 关系并确认 | 真实认证和接受操作提供 authority，不能只信任客户端布尔字段 |
| E07 | 已保存完整意义 | 显示保存结果，打开详情或显式加入学习 | Web 可看到相同事实，不要求二次确认 |
| E08 | 离线/提交失败/结果未知 | 已保存本机、待同步或失败；提供重试 | 请求可能已成功时查询/重放结果，不另建重复 Intake 或成员 |
| E09 | 原页面变化/关闭 | 展示已保存 Context 与原来源；必要时重新定位 | 原网页变化不改写捕获快照，不以 DOM selector 作为唯一依据 |
| E10 | 账号切换/撤销/删除 | 要求回到原账号或停止提交，说明待处理材料状态 | 采集队列不上传到另一个账号；已撤销或删除账号不能继续写入 |
| E11 | 插件更新或与服务端版本不兼容 | 明确更新/恢复说明 | 升级保护待提交材料，不静默解释不兼容 payload |

“保存成功”必须区分本机持久保存、服务器已接纳到收件箱、服务器已接受为完整意义；加入学习
也单独显示 accepted/already-in-scope/preparing/blocked 等实际结果。具体 wire 结果在 M0-3 固定。

## 6. 跨页面通用状态

| 编号 | 状态 | 产品行为 |
| --- | --- | --- |
| G01 | 首次加载/同步 | 稳定的准备反馈，不闪现错误的零进度 |
| G02 | 离线 | 保留已下载内容与本机工作；明确需要联网的操作，不承诺所有流程可离线继续 |
| G03 | 本机已保存、尚未同步 | 显示保存位置和待同步；未权威确认的学习结果不显示成最终结算 |
| G04 | 登录过期 | 重新登录并恢复原账号工作，不清除 pending |
| G05 | 多设备冲突 | 展示服务端当前状态，保留可恢复输入，提供明确处理动作 |
| G06 | 音频不可用 | 可选音频不影响允许的文字学习；缺少必需资源时阻止开始并说明原因 |
| G07 | 退出/清除时存在 pending | 先尝试同步，失败后说明影响，默认保护本机工作 |
| G08 | 导出/删除处理中或失败 | 显示真实生命周期与重试路径；必须联网/重新授权时明确说明 |
| G09 | 账号删除或访问撤销 | Web/插件均停止未授权写入，旧离线操作不得复活数据 |

一个目标可以同时处于“学习中”和“本机回答待同步”。语义阶段、学习阶段与传输状态不能互相
覆盖；插件采集失败不能抹掉已保存的意义，材料删除也不能自动删除已经发生的学习历史。

## 7. 对 PRD 的裁决与下一步

本轮接受的产品变化：首次使用不强制选词书；隐藏未交付主入口；允许自由练习、词典、统计和签到，具体开放条件仍待生产验收；
仅开放轻量学习时省略 Policy 选择器；浏览器采集插件为首轮必交特色功能。PRD 在同次变更中
同步这些范围与入口决定，原型的视觉形态不自动成为正式 Web 或插件布局。

M0-2 [首条状态规格](m0-2-first-learning-state-spec.md)已形成评审稿，新增交互待 owner 确认。
下一步继续插件捕获/确认/收件箱交接的具体交互，核实目标浏览器、
安装更新渠道、支持页面和权限粒度。M0-3 固定首条用例合同、Target 迁移与插件身份/Intake
消费需求；插件领域提交合同须在 M2 开工前完成。

M0-1 完成的是产品范围与基准状态记录。页面走查、浏览器能力验证、UI 规格、生产消费契约和
数据库/Sync 实现仍待后续阶段，不因为本文件存在而记为已完成。

2026-09-07 首条旅程离线范围确认：可继续已授权且材料已下载的学习，不离线新建学习；
本机回答与服务端确认结果分开呈现，具体授权/版本/恢复合同在 M0-3 固定。
