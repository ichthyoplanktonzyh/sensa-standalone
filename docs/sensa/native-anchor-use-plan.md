# 原生原文授权、撤销与后续材料版本

2026-09-09，沿用 M2 Anchor Use 已确认体验。只将固定 sentence 授权给当前选定 Sensa 服务及其 DeepSeek 生成/独立复核；不发送 URL/title/Focus，保留真实人物/事件，原文是数据。默认关闭，明确授权才创建 grant；撤销不可反转，重新授权产生新身份，移除意义自动撤销，恢复不重授。

Rust/SQLite 保存不可变 grant、独立 revocation、固定准备版本及请求历史。当前 logical target 保持同 ID；授权变化终止旧尝试、建立新的准备版本、阻塞未来新 Run，材料就绪后切换目标当前材料。已开始 Run/材料/回答/调度历史不变；后续复习和重学固定新材料。与既有 Web 一致，每个固定准备版本最多三次尝试，授权变更创建新版本；本机及服务账户滚动 24 小时 30 次限制跨版本累计，防止切换授权无限调用。

Hono 复用既有 private-anchor generator/reviewer。只增加 opaque request cancellation 元数据，检查生成前、独立校验前和结果返回前是否取消。Flutter 先提交本地撤销，再尽力通知当前服务取消在途请求；断网或通知失败明确保留本地撤销，迟到结果本地拒绝，不能保证收回已发送内容。地址不匹配时不能带私人原文调用另一服务。

本轮验收：真实 TS assembler 与 Rust CLI/SQLite 合作、旧请求隔离、原文严格范围/接收方、重复/CAS、移除恢复、不重置历史、当前材料切换后新 Review/重学，以及 macOS/Android UI 与冷恢复。全部使用合成资料和无成本替身。事实模型实验不是本轮生产导入 API，不实现同步或迁移用户数据。
