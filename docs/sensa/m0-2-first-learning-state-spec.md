## 2. 本轮范围与页面复用

A：首发允许自由练习、词典、统计、签到。允许开放不等于已生产验收；不自动扩展到所有
Activity、所有词典资源、复杂诊断、额外激励或其他 Later 功能。签到与练习不产生正式
Learning Evidence、学习进度或调度。统计分别表达学习事实、自评、练习与签到，不能用后两者
填充正式完成量。签到入口、跨日与连续天数规则待 Q8，不因允许签到而自动接受完整激励体系。

沿用桌面/手机现有外壳；目标选择/详情用 LearningSetupFrame；学习用 RuntimeFrame，
保持单目标、单主要动作，学习时隐藏导航；账号与每日数量使用现有设置层级。词典、例句、
笔记或场景详情返回原位置，不重置本次学习。生产只开放轻量时隐藏无实际选择的 Policy 控件，
blocked 不再用“换学习方式”作为万能修复。现有首页用 mixed 减 review 推算新学数仅是实现观察；
生产应分别读新学、首学继续、到期复习、重学和去重总数，不将差值冒充新学数。

## 3. 所有页面共同遵守的状态规则

页面组合账号、成员、准备、运行与传输状态；不能压成一个 status。下表 T 规则适用于第 4–6 节
每一行，行内列出例外。主操作只有一个最高视觉层级；重试只在原因允许时出现。

| 编号 | 可见反馈、主/次操作 | 本机与服务端事实；刷新/离开/取消/恢复 |
| --- | --- | --- |
| T0 加载 | “正在读取你的学习”；保留布局；久等可重试/返回 | 未加载不显示 0 或已完成；旧快照带更新时间，刷新重新读取 |
| T1 离线 | “离线”；可用内容继续读取，联网必需动作说明原因 | 已下载内容不等于可离线新建正式 Run。Q5 已确认可继续已授权且材料已下载的 Run，不离线新建 Run；无已授权运行材料不开始 |
| T2 已本机保存/待同步 | “已保存在本机，联网后同步”；次要查看同步 | 只有持久写入成功才能说已保存；意图、原始响应和恢复位置可本机保存，派生完成/调度等待服务端。离开/刷新恢复同一操作 |
| T3 结果未知 | “请求已发出，结果待确认”；主检查结果，次返回 | 超时不等于失败；查询或重放同一操作，不新建另一份提交；取消等待仅离开页面，不撤回可能已接受事实 |
| T4 冲突 | “这项内容已在另一处更新”；主查看最新状态，次保留输入/稍后处理 | 不静默覆盖服务端、不把旧回答套到新 Step；输入保留供解释，按最新合法继续点恢复，Q6 定具体呈现 |
| T5 确定失败 | 原因与可恢复动作；主重试或修正，次返回 | 本机保存失败写“尚未保存”，留在当前步，禁止假前进；网络/服务故障可重试，内容校验/权限拒绝需修正或重新认证，不能无限自动重试 |
| T6 登录过期/撤销 | “请重新登录以继续同步”；主登录原账号 | pending 绑定原账号；切账号不搬运队列。访问撤销/账号删除停止提交；不把普通断网误判为撤销 |
| T7 退出/清除有待提交 | 显示待同步数量与影响；主同步后退出，次暂不退出 | 同步失败默认保护本机工作；强制退出/清除的具体放弃流程属 M3 数据控制规格，不以普通返回按钮触发清除 |
| T8 媒体缺失 | 播放按钮附近说明；次重试 | 可选音频失败可文字继续；必需资源失败阻止受影响 Step，保留 Run 和固定版本；不调用临时生成替换作答材料 |

返回、暂停、关闭弹层不等于撤销语义接受、加入学习或已提交回答；只取消尚未提交的编辑。
不可取消的已接受操作用显式领域操作处理，不把删除来源或清除 UI 当回滚。任何写入都须在
M0-3 有稳定操作身份与版本约束；此处只规定用户结果，不先定 wire schema。
