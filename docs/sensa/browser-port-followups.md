## 优先回访的五项

| 建议顺序 | 问题与优化方向 | 后续验收关注点 |
| --- | --- | --- |
| 1 | 保存状态与故障恢复：在阅读位置区分已存本机、同步中、服务端已保存、重新登录及失败恢复 | 断网、重启、凭据失效、重复点击后，状态真实可理解，原操作可恢复且不重复保存 |
| 2 | 浮层内慢轨澄清：真正歧义时保留原上下文与表达，补一句说明后继续解释，减少跳转 Web | Focus 仍可选；上下文充分走快轨，不充分才澄清；旧候选失效，接受与加入学习保持独立 |
| 3 | 真实模型速度与质量：有界验证首段等待、流式中断、长上下文及不同连接 | 区分协议替身测试与真实 Provider 表现；后续实际付费试验需单独明确预算，不重置已用计数 |
| 4 | YouTube 字幕轨道与不可用状态：切换语言、自动字幕重绘、连续播放及加载失败的恢复 | 减少手动重载；不误用其他语言轨道，不把无字幕当成功，不伪造缺失的句内时间 |
| 5 | 阅读偏好记忆：按网站记住开关、原文/双语模式、面板位置和尺寸 | 重开页面、浏览器重启、账号切换后行为一致；记忆自动翻译模式时明确其模型调用影响 |

重新启动这一方向时，建议先做第 1、2 项；这是建议优先级，Owner 尚未确认下一轮实施排期。

## 与陪读蛙相比仍需补充或验证的范围

| 范围 | 剩余内容 |
| --- | --- |
| 复杂网站适配 | 虚拟列表、嵌套滚动、Shadow DOM、复杂富文本、站点专有结构，以及网站更新后的回归 |
| 长文效率与资源占用 | 批量请求、跨阅读会话的缓存复用、更细的请求优先级、长时间阅读与多标签页的资源表现；现有视口调度和会话缓存不是全部缺失 |
| 视频覆盖面 | 更多字幕格式与重绘模式、Shorts、跨域嵌入、直播及无字幕内容的转录路径；具体采用范围需要产品取舍 |
| Provider 配置广度 | 更多原生协议、模型/推理参数、连接诊断及跨端配置体验；现有兼容接口与服务端凭据方案继续保留 |
| 产品成熟度 | 安装引导、升级和权限变化后的恢复、多标签页协调、浏览器重启后的连续性、长期真实使用回归 |

这些是基于已阅读源码和本项目验收所识别的差距与待核查范围，不是对陪读蛙每项能力均已成熟的断言。
参考版本固定为 Read Frog v1.46.8、提交 `e3cbe2b7c669c875dbf1b050254da9b628daefe1`，
并非持续跟踪上游最新版。

## 差距判断与恢复工作方式

常规网页与有英文字幕的 YouTube 核心流程已有较多覆盖；复杂场景、兼容性和长期稳定性的
差距仍需同场景对照。当前证据不足以给出可信覆盖百分比，或宣称与陪读蛙整体体验基本一致。

后续先选 Owner 常用的网站和视频做持续使用记录，按阻塞程度决定投入；不要求对齐陪读蛙
全部功能之后才能推进其他采集端口。Sensa 的目标仍是从多种场景保存上下文、目标 Sense 与
Expression，浏览器只是其中一个采集端口。

继续遵守闭源边界：可阅读陪读蛙源码理解行为，独立实现，不复制、转译或引入其实现。
本次只记录并结束当前优化轮，不启动新的开发、后台监控、付费调用、推送或部署。
