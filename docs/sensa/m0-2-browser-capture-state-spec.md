## 1. 当前确认范围与基线

插件是便捷获取阅读材料的主要入口。首版默认桌面 Chrome、文字采集、中文解释英语表达；
不扩入图片/语音、后台整页采集、MCP、多端插件或正式学习 Runtime。原型代码现存
`apps/web/src/experience/components/IntakeSimulatorModal.tsx` 与
`personalMeaningJourney/intakeEngine.ts`，只证明本机分流，不证明真实捕获或生产授权。
初始评估后 Web 重构已存入 checkpoint `5fee636e`；本轮只整理文档，不改实现。

本稿已将本任务的 owner 确认合并为现行规格。此前弹窗加侧面板、手动点解析、语境编辑、
匿名采集和单独统一采集入口的讨论均不再是现行方案。参考 implementation_plan14.md 仅帮助
理解摄取思路，不采用其中的自动 Default Focus、MCP 和多端实施指令。

已确认的正常流程：

1. 登录 Sensa；已有有效同账号认证时尽量不重复登录。
2. 点击工具栏 Sensa 图标开启当前标签页阅读模式。普通模式不干扰划选/复制。
3. 选中表达，系统使用所在句子，自动在选区附近显示原句、高亮表达和简明句中解释。
4. “加入 Sensa”一次性表达对当前完整关系的确认与保存；“保存待处理”保留材料而不接受解释。
5. 成功后短暂提示并收起，留在原网页；可选查看，不自动打开 Web 或加入学习。

同标签页继续浏览时保持模式，其他标签页不自动开启，关闭标签页后结束。跨站权限的实际
限制见第 6 节/P1；不得用模式已开冒充页面已有读取权限。浏览器重启后恢复标签页是否开启
尚无承诺，初始实现默认关闭，不自动恢复抓取。

首版不提供插件聊天或“调整语境”。选错表达关闭后重新划选；解释存疑保存待处理，后续在
Web 继续。owner 已确认首版只提供直接选表达、自动取所在句子的路径；先选句子再选表达的双次划选
不纳入首版，后续根据实际试用需要再评估（P3）。

## 2. 表面与组件状态

| 表面 | 呈现与操作 | 状态来源 |
| --- | --- | --- |
| 工具栏入口 | 账号、当前标签页阅读模式、必要的权限说明与待保存/同步状态恢复入口 | 账号服务、当前标签页模式、本机队列分别读取 |
| 就近浮层加载 | 原句、表达高亮、“正在解释”；可保存待处理或关闭 | 原句来自此次明确选取与必要句子范围；加载不是接受事实 |
| 解释结果 | 简明句中释义；“加入 Sensa”与“保存待处理”；详细释义按需展开 | 候选含固定 Context/occurrence、Sense/Binding 与版本，服务端校验后方可接受 |
| 成功提示 | 完整意义：“已加入 Sensa”；Inbox：“已存入收件箱”；离线：“已保存在本机，联网后同步” | 分别基于服务端接受、Inbox 接纳、本机持久写入成功 |
| 失败/未知 | 原位说明原因、重试或检查结果、保存待处理等合法出口 | 不能用通用“失败”覆盖可能已接受的提交；不能只用短暂 toast |
| Web 查看 | 原意义/Inbox 详情；现有“我的内容”按最近加入找回 | 不增加统一采集入口；完整关系不重新进入 Inbox 或接受流程 |

浮层保持当前 Web 字体/色彩语义；不遮挡关键选区，靠近边缘时向可用区域避让。长原句换行、
长内容可滚动；不因尺寸限制静默截断待保存原文。关闭按钮和 Escape 可离开；点外关闭延用
轻量浮层提案，保存已发出的操作继续按稳定身份恢复。成功提示在键盘焦点/指针交互期间
不自动消失，“查看”始终能从工具栏最近结果恢复，用户不必抢点短暂按钮。

句中解释本身可供查阅，只有显式保存才创建持久 Inbox/完整意义。未点击保存的临时选区不
自动变成永久材料；刷新/关闭可能结束该预览。已发起保存的输入必须先持久保护，失败须说
“尚未保存”。原位临时结果与待提交队列不能共用一个会随关闭清空的状态。

## 3. 捕获、解释、保存矩阵

所有行继承首条规格 T0–T8；状态组合账号、采集完整性、服务状态与同步状态。

| ID / 状态 | 主操作 / 次操作、反馈 | 离线/失败/未知/冲突；刷新/关闭/取消/恢复与权威 |
| --- | --- | --- |
| E01 未安装 | 安装说明 / 返回 Web | 不以点击安装链接判断已安装；渠道按已确认 P2，安装/更新能力仍需真机验收 |
| E02 未登录 | 登录 / 返回 | 登录前不开启自动解析或匿名采集；认证取消留在原网页；过期账号的已有 pending 保留原归属 |
| E03 模式关闭/无选区 | 工具栏开启 / 普通阅读 | 不请求解析；开启不扫描上传整页，只处理之后明确选择；无选区不创建空材料 |
| E04 无权限/受限页面/读不到句子 | 重新授权或重新划选 / 到 Web 保存材料 | 说明具体可恢复原因；不要求无关权限，不伪造上下文；无合法 Context 不能快轨 |
| E05 选中表达 | 自动解析 / 保存待处理、关闭 | 固定原句、表达 occurrence 与来源；只提交此次必要范围。重新划选后旧结果不覆盖新浮层，也不能确认成新表达的意思 |
| E06 表达不明确/多句选区 | 说明需定位表达 / 保存待处理、重新划选 | 不把任意段落自动当完整表达；缺项进 Inbox，不伪造 Sense；双次选取不纳入首版（P3） |
| E07 保存待处理 | 保存 / 关闭 | 原句/表达/来源持久保护；服务端接纳提示“已存入收件箱”后收起；离线只提示本机待同步，随后收起；都不自动打开 Inbox |
| E08 正在解析 | 等待 / 保存待处理、关闭 | 同一请求可查；不盲目重发超时请求；解析未完成不禁用已有合法材料的待处理保存；关闭不承诺远端计算被撤回 |
| E09 解释可用 | 加入 Sensa / 保存待处理、关闭 | 当前完整关系经用户动作接受；模型输出不是接受；无语境编辑/聊天；版本冲突先读当前结果，不默默接受旧关系 |
| E10 解释存疑/语义未闭合 | 保存待处理 / 关闭 | 不强行确认，不默认取第一个义项；后续在 Web 补齐；保存候选不把它标为已接受 |
| E11 正在加入 | 等待/检查结果 / 关闭 | 防连点；超时进入结果未知，查询/重放原操作；关闭不是撤销，原账号重启可恢复 |
| E12 完整意义已保存 | 短暂成功提示，可选查看 | 提示“已加入 Sensa”并收起；留原网页，不自动学习；Web 读同一 Meaning/Alignment，不重复确认 |
| E13 重复保存 | 已加入 Sensa、查看 | 同句同表达已保存不重复创建；不同句子允许新语境。跨来源同文本/多 occurrence 细则 M0-3 核对，不能只按词形合并意思 |
| E14 解析/保存确定失败 | 重试 / 保存待处理或关闭 | 解析失败/断网显示“暂时无法解释”；保存失败显示尚未保存，留恢复操作；重试不重建已接受结果 |
| E15 用户关闭/取消等待 | 回网页 | 未保存预览不承诺永久保存；已开始保存的持久意图保留。取消等待不撤回接受；删除已保存内容在 Web 用独立操作 |
| E16 网页变化/关闭 | 查看已保存快照 / 打开来源 | 原页面变化不改历史 Context，selector 不是唯一定位；重采是新明确意图，不能覆盖旧来源 |

技术幂等与产品重复保存分开：连点/请求重放必须同一结果；不同句子的合法材料可各自保存。
Curriculum 按目标去重，不从重复调度反推应删除个人语境。加入学习可在 Web 明确触发，
沿首条规格 B02–B06，ready 后回首页开始；原位保存不自动越过这条边界。

| H08 跨日/换设备 | 根据已同步状态继续 | 未同步只在原安装；首次学习仍须确认每日数量；采集/查词不触发正式学习或签到 |

## 7. 组件与验收要求

继承首条规格可访问性和性能要求：键盘选择可用，浮层可从工具栏聚焦，Escape/关闭回合理
位置；非模态浮层不锁住整页，不能夺走继续阅读的焦点；隐藏结果不可聚焦。状态可读且不只
靠颜色；普通正文目标对比度 4.5:1、关键非文本 3:1、按钮目标 44px。原句换行、边缘避让、
滚动后锚点失效和 200% 文本缩放列为实测场景。没有聊天、侧面板或语境编辑的测试前置。

自动解析仅在完整选区确定后发起；拖动中不重复请求，同一选区合并请求，旧响应不能覆盖新
选择。解释内容延迟和浮层反馈分别测量；目标本机反馈 100ms 内，长请求给稳定加载和退出
路径，实际 provider 延迟/预算单独验收。未点击保存的查询记录不得作为个人意义库存。

关键端到端验收：阅读模式开关/跨站权限；真实句中查询→确认→Web 同一意义；待处理→Inbox；
同句重复和不同句保存；连点/超时/离线/重启；另一账号；页面变化；更新中断与数据删除屏障。
每项记录 UI 结果与服务端事实，不能用模拟器或构建成功代替。当前未操作浏览器/插件或调用模型。
