# 本地优先与普通账号云同步

## 决策与原因

Owner 确认首发采用“本地优先＋普通账号云同步”，先交付其他用户能够真实使用的 React Web。
原生端只保留架构边界，本次不交付原生内容。为减少首发实现与使用复杂度，撤销此前
“服务器不能解密个人库”的要求；不将端到端加密、恢复码或已授权设备批准作为首发前置。
文件路径保留以维持既有引用，原加密决策可通过 Git 追溯。

## 职责与用户体验

- Web 本地库保存个人内容、学习资源、学习集合、学习历史和必要的当前状态。已初始化库在
  断网或在线会话失效时仍可使用已有资料学习，本地领域执行层校验并提交结果。
- 用户登录账号后同步已保存资料。云端保存账号隔离的持久副本，支持其他浏览器登录后下载
  已同步数据；只有尚未同步的本地变更不能由云端恢复。
- Hono 可以读取和处理同步业务数据，提供认证、同步、资源及模型服务；不承诺服务端无法
  读取个人内容。采用 HTTPS、受限访问、用户隔离和备份保护，不能把普通云存储称为 E2EE。
- 本地提交与待同步变更应原子保存；上传可重试、按稳定身份去重，收到确认后才移除待传项。
  云端支持首次下载与增量补齐。内容引用与媒体文件传输分开，恢复必须包含所需附件。
- 学习记录不得被整库覆盖或内容的最后写入规则抹除。UI 不能绕过领域校验写派生结果；
  同步不得重复产生学习结算。Owner 已确认首发冲突保留双方并提示处理，独立修改正常合并；不预建通用多端自动裁决框架。
- 模型只处理请求所需内容。用户自定义模型密钥继续本机保存，不因普通账号同步自动上传。
- 同步、备份、账号删除与本地清除仍是不同操作；同步不等于误删恢复。

## 范围与验收

首发主链是登录、创建或采集内容、准备资源、加入学习、本地学习、账号同步，以及在另一个
浏览器登录后恢复内容和学习进度。复用已有 Web 页面、学习扩展机制和本地执行层。
验证断网续用、重试去重、账号隔离、媒体恢复及会话恢复；不以原生交付、跨语言一致性或
任意多设备并发离线自动合并作为首发前置。

现有加密采集信封仅是已有实现，不是新首发同步合同。恢复码/设备批准入口及专用交付链需要
随普通账号同步接线收敛，不据此继续发布旧加密方案。原生与 E2EE 均未安排新的实施阶段。
旧 API 的服务器执行型 sync 只可复用经核对适配的部分，不能直接接到本地库便宣称完成。
此决策不代表账号云同步已经实现，不授权自动迁移 owner 数据、推送或部署。
