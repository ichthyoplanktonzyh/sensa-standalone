# 本地优先与普通账号云同步

生产 Web 以浏览器本机学习库为交互和事务入口，并通过普通账号同步到云端。已初始化的本机库可以在网络或在线服务暂时不可用时继续使用已有资料；同步失败不撤销已经成功的本机提交。

云端副本允许服务端读取业务数据，不承诺端到端加密。恢复码、设备批准和 E2EE 不是当前 Web 的前置能力。

同步必须满足以下边界：

- 本机提交和待同步状态可靠保存，重复传输幂等；
- 学习操作与事件历史不可被整库覆盖或改写；
- 启动不等待完整云恢复，同步进度和失败单独呈现；
- 内容变化、重新联网、窗口聚焦或账号接通可以触发同步，空闲标签不轮询；
- 同步、备份、退出登录、清除本机数据和删除账号是不同操作；
- 不自动迁移、删除或重解释 owner 数据。

当前实现和验证入口见 [`docs/sensa/engineering.md`](../sensa/engineering.md)。
