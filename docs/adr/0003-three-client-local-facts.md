# 三端本地执行与共同事实模型

> 2026-09-11：首发改为 Web 本地优先＋普通账号云同步，见 [ADR 0001](0001-local-library-optional-encrypted-sync.md)。本 ADR 的原生架构保留；旧 E2EE 限制及原生优先交付顺序不再适用于首发。

Owner 确认 Web、原生桌面与移动端的完整本地使用终景，以及“可追溯领域事实、版本化变更、可重建当前状态”的共同学习库模型。原生继续 Flutter/Rust，Web 保留 React/TS 并在原生迁移后改造本地领域执行；Hono 提供可选 E2EE 同步、账号/设备、资源及模型服务。BYOK/本地模型与 Sensa 托管能力作为可选择的 Provider；本地学习不依赖在线服务。

本决定更新 ADR 0002 中“Web 是否开放以后决定”和“TS 仅保留作迁移对照”的终局范围；近期仍优先完成原生迁移，未授权本轮直接重做 Web。Web 与原生独立运行，但共享领域身份、事实合同和合并规则。保留 TS/Rust 双实现意味着必须维护跨语言一致性证据；Rust WASM 仍非前置。

同步传输已提交事实、版本变更与必要附件，不重放 UI 命令或模型调用。接受、评价和结算的历史依据保留，当前进度/调度按有效事实重建。个人意义修改不能改写已固定 Run，目标身份跨设备/内容版本稳定。同次 due 并发学习须保留分支并经显式裁决最多应用一次，不能最后写入覆盖或直接累加。具体评分裁决、分支后继、设备权限与加密协议尚未定案；本决定没有接受“取最低分”这一实现捷径。

校验从现在开始分层进行：模型不变量 → 原生真实事务/多副本 → Web 本地与 TS/Rust 差分 → 三端及 E2EE 服务验收。不能等全部客户端完工再首次验证模型，也不能把模型实验称为生产同步。执行与证据见 [事实模型蓝图](../sensa/personal-library-fact-model.md)。


2026-09-10 体验层修订：首次创建账号/登录是默认必要入口，Sensa 为默认在线服务，BYOK 为高级选项。
本 ADR 关于无在线依赖的条款约束已初始化本地库的执行与持续可用性，不再要求首次使用提供免账号旁路。
首次入口变化不转移学习事实权威，不取消离线继续、个人资料所有权或可选同步。
具体用户旅程以 [PRD](../sensa/product-requirements-v1.md) 为准。
