# 本机事实与云端 Checkpoint

本 ADR 细化 [ADR 0001](0001-local-library-optional-encrypted-sync.md) 的同步触发方式。

生产 Web 的每次用户操作先由本机 SQLite 领域事务完整提交。本机提交成功就是当前设备上的保存成功，
不等待云端确认；云端同步只负责把已经提交的当前事实收敛为可供另一设备继续使用的 Checkpoint。

账号接通后首次拉取在后台运行，不阻塞应用外壳或已有本机资料。之后只有存在尚未进入 Checkpoint 的
本机版本时，才在静置一段时间、连续使用达到上限、完成学习会话、页面转入后台、恢复联网或用户
主动要求时批量同步。回到前台只在云端检查已经过期时拉取；无本机变更且检查未过期时不请求整库。

同步以本机内容版本和已确认基线判断是否仍有待传输事实，不能用一个可被并发写入错误清除的布尔值。
同步期间发生的新提交必须留给后续 Checkpoint。

云端 Checkpoint 保存当前领域事实、不可改写的学习事件和跨设备重试所需的紧凑幂等回执。仅用于本机
命令返回的完整结果不作为永久云端历史反复传输；相同媒体按内容摘要复用传输块。压缩传输记录不得
删除或重写 Personal Library Fact 或 Learning Event。

Remote Intake Delivery 是独立邮箱；它只等待本机账号库身份稳定，不能自行启动整库同步，也不能因为
一次空邮箱或网络失败显示“内容仍在队列”之类未经事实支持的全局提示。

同步状态只在账号与设置中按需查看；正常同步不占据全局界面。只有长期失败、退出或清除本机资料会
丢失待同步事实、以及新设备恢复明确失败时，才需要在相应决策位置提醒。

Cloud Checkpoint 仍不是备份。未来 Account Backup 必须产生完整、不可变且已验证的 Recovery Point。
